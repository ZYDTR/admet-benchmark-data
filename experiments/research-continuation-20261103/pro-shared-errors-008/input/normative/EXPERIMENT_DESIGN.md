# ADMET 实验研究纲领

2026-11-02。主控制定问题、研究者形成方案、准备方实现科学接口、训练方执行已登记实验时共同使用。本文是本项目长期指导，不是某轮临时补件；具体任务和数据权限由项目入口与当次任务确定。依据工作区 Best Practice Skill Writing，以可证伪结论和可比较实验为目标，不规定固定CLI或全流程脚本。

## 质量、研究深度与反馈速度

2026-11-02用户明确：Token成本和已授权可用算力不作为节省目标。以提高预测质量、充分理解问题和取得有信息量的实验结果为目标；不能为了少用Token/GPU缩减关键材料、分析深度、候选覆盖或有价值的重复验证。资源登记用于安排执行、估计完成时间和保护他人任务，不是要求寻找最便宜方案。

控制的是反馈链中的无效等待。已有充分依据且不依赖未决结论的批次可先执行，研究同时继续；需要关键证据的实验则保留真实依赖。不必等数小时的完整报告才交付任何下一动作，也不把“五小时”变成强制截断分析的时限。优化重复核验、交接空等和不必要的串行运输，不能靠少分析或少取重要证据提速。

实验空间包含连续参数、底座、表示、损失与数据划分的交互，通常无法穷举。对科学问题定义清楚的有限候选集可以充分并行比较，但不能用无依据的全组合替代研究。保留有理由的多样探索，用结果区分竞争解释、修正判断；不因便宜而永久只微调现有小头，也不因贵而排除有希望的新表示。广泛实验仍须解释其预期质量收益或信息价值，冻结、标签及不影响他人的边界继续适用。

## 每次实验应带来什么

先说明要解决的质量问题、已有证据、竞争解释，以及哪种结果会改变下一步。候选可以广泛，实际矩阵按预期质量收益、信息价值及依赖关系选择；准备度影响启动顺序，不能作为系统性排除重要方向的理由。训练很快时可组成充分覆盖的批次；一次研究支持多个批次和条件分支，避免每训一个头再等待一次研究。已完成的等价对照直接复用，重新运行须有明确新增信息。

比较单位包括任务、输入版本、冻结表示、fit/stop划分、预处理拟合范围、训练目标、早停、seed与外部指标。单因素实验确实只改变一个因素；多因素组合先归因于整体，必要时再拆解。模型seed变化与划分变化分别登记。两seed是有限稳定性证据，反复使用Valid会产生选择偏差，不能把一次最佳值或新会话当独立泛化证明。

## 具体盲区与解决证据

目标是知道模型在哪些分子群、什么条件下失效或存在未检验风险，并让后续结果改变对同一问题的判断。任务含义、标签来源、单位和评价口径决定正确性；模型信心、模型间共识和高总分都不能替代独立证据。以下是研究交付的结果标准，分析手段、样本量、切片方式和执行顺序由研究者选择，不规定固定扫描脚本或每轮检查清单。

| 必须能回答的问题 | 足以复查的结果 |
|---|---|
| 具体是哪一群，为什么关注？ | 稳定issue/cohort身份，task、split、数据/模型版本、选取依据和时点、数量及完整成员位置。原行身份用task/split/row_index及输入版本定位，不能只用可能重复的Drug_ID。可展示代表例，但保留按定义得到的完整群及覆盖分母，避免凭几个醒目例子泛化。 |
| 是可疑现象还是真实错误？ | 分开记录无标签的分歧/极值/分布外线索、train内独立于该次fit的验证证据、获准的Valid汇总诊断。说明证据能支持什么；既往参与训练或选模的样本不能改称新独立检验。无真值只称风险候选，不把分歧最大的模型判为错误方。 |
| 哪种解释值得检验？ | 记录机制假设、合理的替代解释及其不同预期；已知实现错误可直接定位修复，不为凑数量虚构竞争假设。实验关联issue，给匹配对照、变化因素、观察指标，以及何种结果支持、反驳或缩小解释。探索性发现如实标注；确认性判据在查看其结果前记录。 |
| 这次到底解决了什么？ | 在可比较的同一群上记录改动前后结果、样本量与不确定性，并检查影响决定的其他群退化。问题改善与机制被证实分开；只支持部分范围就缩小结论。涉及新表示/划分或发现新分歧时，判断旧群是否仍覆盖风险，需要时另留新群，不能移动旧群成员制造改善。 |
| 后面如何接续或收口？ | 同一issue链接证据、proposal、实际run和后续结论。区分待验证、支持/缩小/推翻某解释、部分改善、在限定范围解决及暂缓。关闭须有对应问题的证据、判据和剩余风险；暂缓写原因与重开条件，不要求每个问题立即解决，也不因平均分改善自动关闭。 |

寻找盲区时，分歧、极端预测、结构/scaffold、与train距离及标签范围可提供线索。还应考虑共识或看似容易的区域是否从未受检，因为模型可能共同犯错；按任务风险、现有覆盖与证据选择，不能将视觉任务的正例/边界/负例分层机械搬到所有ADMET任务。分类概率的极端值本身也不证明已校准。保留有根据的覆盖探索，不强迫每项新底座研究先找到已知错误才准入。

当前证据边界：可使用获准的train内holdout/OOF结果及官方train标签；需要新训练/编码/预测时按既有派发与预算交执行方。拟合样本上的误差只作诊断。Valid真值和逐行残差仍由指定评分角色按本次准入处理，研究者可给出有科学理由的群定义，请其返回获准汇总；小群或反复重叠查询不得透露个体答案。发现于反复使用的Valid上的分群与改进属于探索性选模证据，不宣称独立泛化。证据不足时明确所缺检验；禁止用LLM补标签、改实测Y或借盲区分析拟合test。

例如，既有PPBR预测尾部变化只能提出“少数高差异分子可能受尺度处理影响”。可保留该群并比较尺度敏感与表示不足两种解释，在允许的train内检验及匹配实验中区分；预测变平滑不等于误差降低。这个例子规定结论的证据要求，不规定必须采用某个阈值、模型或实验次数。

把精力用于会改变决定的缺口。重用未变群、已有评分和可信证据，只为新模型实际影响的风险或反证补检；不对每个新头做一轮全库审计，不让一个未解问题阻塞独立的已就绪批次。关闭或暂缓依据问题证据、覆盖和剩余风险，不以Token或算力省钱为理由。

## 可复用的方法与适用条件

| 方法 | ADMET中的判断和交付 |
|---|---|
| 冻结表示与简单对照 | 在相同特征上考虑线性/逻辑回归、正则回归与现有MLP对照，先判断复杂头是否带来稳定收益。简单头需要新接口时明确标注；纯经典模型能否作为正式参赛模型另核规则，研究对照与提交资格分开。 |
| 表示和缓存 | 把表示、池化、特征尺度与获准冻结底座作为科学因素。缓存绑定原行、编码器和配置；每个fit划分独立拟合统计。共享编码降低重复成本，不假定大底座更好。 |
| 与任务匹配的目标 | 结合类别不平衡、标签分布及评价指标，比较适用的损失/权重/尺度。权重仅从train-fit统计；加权与不加权保留对照。训练loss、早停指标、外部指标及预测尺度分别具体定义。 |
| 更可靠的泛化检查 | 在官方train内部评估规范化分子身份、相似性或scaffold分组的压力测试价值；原始行和官方分区保持不变。先查已有划分，不能凭分组方法缺失认定官方泄漏，已看过的Valid也不能事后重新宣称独立。 |
| 分歧和困难样本 | 复用已有预测，按上述盲区结果标准把统计线索落实为可追踪的具体群；把跨模型分歧与可能共同犯错的区域一起纳入风险判断。 |
| 按信息价值组织实验 | 区分假设的对照、充分的seed/划分确认、新表示和结构探索可组合或并行，不固定先做廉价筛选，也不固定只探索少量方向。给继续/停止/扩展条件和对照复用账；需要测量新工作的资源峰值时测量，不为每个已知小头再建试跑流程。 |

跨任务保持覆盖，又允许分类、排序和回归任务采用不同策略。对改善、退化、方向不一致分别解释；一项预处理有效不能推广到所有任务。下一批指南写到执行方无需猜测科学参数，同时允许其自行解决工具、部署和运行细节。

## 沉淀与验收

研究结果必须落入持久实验索引、问题账和结论事件。每个方向对应历史已做/未做/已否定/有条件复试的证据；旧结论被推翻时保留旧事件、反证和影响的方案。一次完整交付含具体矩阵、可执行准备指南、资源/时长估计及未知项；能说明所选实验检验什么、结果如何改变后续动作。等待须对应实际依赖，不能只因另一份报告尚未写完；候选不能仅因Token或GPU用量被裁减。研究者可用代码做获准的数值诊断，但不能将推理或计算结果冒充真实训练或官方评分。

主控评估新增主张和下一动作，复用已有可靠评分、冻结与运输证据，不重做整份研究。用户要求结果优先于过程，验收依据是科学问题得到可检验回答，而非工具调用数、报告长度、脚本PASS或多个模型口头赞同。
