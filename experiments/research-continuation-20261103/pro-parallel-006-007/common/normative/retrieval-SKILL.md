# ADMET 训练产物取回（沿用历史Skill名称）

Workflow。v1.6.0，2026-11-03。主控或用户明确指定的专用取回会话使用。写作依据：[工作区Skill标准](../SOURCES.md#ref-d05da2626832a70e)。负责指定宿主评分、Pro研究所需材料及可追溯来源交付。先读[存储与运输入口](../SOURCES.md#ref-9bdeeffcf8113516)和实际切换状态，落地到登记项目路径；存储在mini不改变评分执行身份。当前[研究模式](../SOURCES.md#ref-e13881cdb124214a)支持Astra/Pro并行：本地研究直接接收批准路径，Pro旁路有具体发布任务时才整理/发布公开增量，不能让其等待挡住本地研究。Chat往返仍由网关负责。完整历史与首测证据见文末，当前方法以本任务范围和结果为准。

本版共同交接规范见[控制合同](../SOURCES.md#ref-a143757d86c87f68)与[角色模板](../SOURCES.md#ref-70ad9a65eea3ced1)。本次任务绑定Skill、命中引用、输入、预算和验收版本；旧run证据不回写。职责之外的规范不扩大本角色权限。

本地及公开研究交付均须对照主控最新 `control/history-registry.json`，让全部相关历史可导航，包括最早Mini 22任务基线、准备对比/未就绪底座、失败和评价使用史。按[证据复用约定](evidence-reuse.md)，已验且已发布的历史以固定commit/对象链接复用，新增和变更才重新取回、处理、验证和发布；不每批复制全部历史。本次确需的新材料补齐，原来没记录/需新实验的缺口如实保留；仅远端保存、尚未下载的完整原件不能冒充科学缺失。本地交付给准确路径/来源及允许读取范围即可，公开分支另给真实固定链接；本地可读与公开可读不混称，不为Astra重发布或下载已有材料。

取回Agent在既有权限内自行选择清点、传输、重试和核验方法；没有固定collector或流程检查器不阻断任务。格式示例用于表达证据，不要求机械复刻目录。下文评分计算沿用已审读的数学口径，不能用过程灵活性改变评价定义。

按[端到端约定](evidence-reuse.md#缩短端到端等待)区分可评分、研究材料就绪与完整归档完成。消费已有可信对象；本次Pro问题需要的材料完整收集，依赖已齐即可交付。原件完整保留在训练主机并可访问，不等于必须复制到接收端；不得为Astra安排归档尾单。传输合并、流式压缩、连接复用或有限并发由Agent结合真实瓶颈选择，不规定每run单独连一次。保持远端只读、不落压缩临时文件、任务资源受控；现有组合计时只能说明应用有效吞吐，不足以判定网络带宽瓶颈。

## 目标与唯一连接入口

把具体Pro研究请求所需材料或固定评分必要输入完整、可追溯地取回登记的mini项目目录，证明取到了什么、缺什么、是否逐字节一致，以及各阶段花了多久。优先保留原始材料，摘要作为衍生产物单独生成。2026-10-31 用户明确本角色还负责本机 valid 评分及证据打包/发布，任务级/分组级精确汇总评分和技术诊断可由主控纳入准备/训练反馈，逐行valid真值与残差仍只在获准的评分/分析范围内。规则见[评分与发布](scoring-and-publishing.md)；取回角色与 Chat 双向网关保持分离。

按[算力池路由](../SOURCES.md#ref-d1feb10a7c021b02)及训练方跨主机清单确定(host_id, absolute_path, run_id, attempt)，不能根据历史run名字含hainan推定源主机。138使用对应连接引用，只读范围保持不变；同run在两台的失败与完成原件均保留，可信已取对象复用。所有海南连接必须先完整读取 [hainan-compute-access](../SOURCES.md#ref-57d98b92e83b2330) 及其 [连接基线](../SOURCES.md#ref-8459f195e9181be1)。原有Windows通道、双层严格主机密钥、h100/UID1012、project-owner目录边界、凭据仅内存和有界恢复全部继承，不另维护更宽的连接规则。只读连接脚本的三个动作不能替代本任务明确授权的文件取回；扩展实现仍须审读实际命令及副作用。

ADMET取回另读 [宿主唯一入口](../SOURCES.md#ref-efaee4d3b1b9e111) 和对应policy。它的训练计划不赋予本取回任务训练权。本次范围由独立的 `RETRIEVAL_TASK.json` 指定，包括源run、可读依赖、主控本地参考、落地目录、预算及是否实测全量传输。

138按[连接引用](../SOURCES.md#ref-5a5eb9623d54a6a7)首选经217、直连备用，记录实际线路及恢复耗时。217仅临时转发，和源主机一样不落压缩包、临时文件或凭据；接收端仍在获准本机目录。切线路保持原对象身份，可靠已收对象复用，新传输仍按原摘要核验。不能把观察用短连接示例的超时当作大文件上限，也不能把跳板登录成功当作传输完成。

## 质量材料的覆盖

根据本次Pro问题及评分用途清点有来源的独占run，登记所需对象、远端保留对象和可复用历史。下表用于判断质量信息覆盖，不是全目录下载清单；未取回项有可定位来源和原因。必要assets、特征或失败原件不能因旧collector白名单漏掉；是否运输取决于本次实际用途，不为Astra或泛化的“完整归档”默认搬运所有文件。

| 类别 | 应保留的已有原件 |
|---|---|
| 实验身份 | run/计划、实际配置、完整执行源码与补丁、固定资产版本、启动命令及环境摘要、历史尝试和决策依据。 |
| 输入与划分 | 实际train及获准盲输入、原始行身份、内部划分索引、变换参数、单位/标签转换、解析和截断/失败掩码。 |
| 学习过程 | 已有epoch/batch指标、学习率、梯度统计、优化步、最佳轮次/早停、恢复和失败日志。 |
| 预测与表示 | 已生成的逐样本预测、底座表示/特征缓存、预处理结果、顺序和缓存身份；保留空/重复ID和全部原行。 |
| 模型状态 | 原底座资产、最佳/最终头、已有中间checkpoint、优化器和随机状态、冻结前后参数/buffer证据。 |
| 可复现环境 | 解释器及依赖清单、版本/摘要、项目定制代码/二进制、精度和硬件/驱动记录。当前环境快照须标注采样时间，不冒充训练当时状态。 |
| 运行与异常 | 作业相关stdout/stderr、退出状态、OOM/资源样本、系统调用轨迹和拒绝记录，包括失败尝试，保留其与本run的关联。 |

权重、输入、已取回原件跨run或角色相同，可使用已有可靠验收及身份绑定并写明引用，不由每个角色再逐字节全验一次；新传输或可疑副本仍由接收方验证。**测速任务要求全量重新传输时，不能拿历史本地副本冒充本轮下载**；分别报告新下载和复用字节。依赖安装目录可按任务仅取元数据而不复制全树，但须列为明确排除项及复现限制，不能宣称全环境快照。

没有保存的train预测、batch日志、中间checkpoint或优化器/RNG状态应记 `not_recorded`，不能通过重新训练/推理补造原轮证据。相关文件不可读与当时没生成是不同状态。保留完整性与语义质量两个结论：文件全取回不证明训练科学结论正确。

## 执行边界

- 远端只读：清点、读取、哈希和从stdout流式传输；不在任何源训练主机或中转Windows创建压缩包/临时文件、安装依赖、改权限、停止服务或清理文件。普通Python读取使用隔离模式及禁pyc；不导入会初始化CUDA/写缓存的训练框架。必要系统元数据仅限身份和与本任务相关的环境，不扫描他人目录。
- 接收端只写当次明确登记的项目取回目录、私有评分输出与发布工作副本，按storage入口落在mini；这些不同用途的路径须在任务清单中列清，不能把“只写取回目录”误用于阻断已授权评分/发布。保留原件、失败尝试和日志。历史run、Skill、验收标准由主控维护，执行方不得修改。不执行原始模型/pickle、不加载模型、不训练或推理；张量/归档结构检查使用不执行代码的读取方式。已获准的固定预测评分仅按评分与发布参考执行。
- 凭据不进入argv、产物、报告或工具输出。结构化文本错误可脱敏；二进制产物流不能做字符串替换或编码转换，防止字节损坏。密钥/身份变化和真实文件权限拒绝为硬失败；短暂连接异常遵守连接Skill的有界退避，取回失败留下partial，不能伪装成功。
- 身份及终态核实后才固定快照。验证路径、真实祖先和挂载，远端清点不跟随符号链接，不自动越出批准根读取依赖。特殊文件、链接或路径漂移单列拒绝/缺口，不能悄悄跳过后报完整。读取多硬链接普通文件须登记且限真实批准路径，只读不修改；本地不要重建硬链接。
- 本地解包拒绝绝对路径、`..`、符号/硬链接、特殊文件、重复归档名称和越界目标；设声明大小/总量预算，独占目录中排他创建文件，不使用可能覆盖原件的解包或同步删除选项。
- 只有任务相关授权材料能取回；远端不搜集验证/测试真值。用户已指定的本机 valid 评分仅访问登记的真值来源和固定评分器。发布阶段按评分与发布参考处理，保留接收对象、材料范围和读回证据；上传到共享文件区与向 Chat 发送分析消息由不同角色负责。本Skill不自动新增训练、会话或定时。

## 完整性和测速的证据

清单应能定位每个对象的相对路径、类型、字节数、摘要及来源；已有可信清单可引用，目录和拒绝项也纳入覆盖统计。源稳定性可以由已验的退出后清单与实际原件证据证明；缺少终态、文件仍在变化或来源矛盾时才补前后清点，不默认每批两次全目录远端哈希。变化的文件进入 `source_changed`，重试另存独立attempt；不把两次不同源状态拼成同一快照。

新接收文件由接收方一次核对路径集合、字节数和摘要，记录缺失、额外、摘要不符。完整源目录须有与本次作业关联的源端证据，不能仅凭归档自带清单自证；训练方已提供并验收的直接源端终态清单可复用，不要求取回方再远端读取同一整树。缺少的对象及结构覆盖由本角色补查，已验的配置/训练记录不重复全查。新增预测的全行身份在固定评分入口检查一次，主控消费回执。

计时使用本机单调时钟，记录UTC原始时间及北京时间展示：

- `setup_seconds`：读规范、准备实现及离线检查，单独记录，不混入网络速度。
- `connect_seconds`、`inventory_hash_seconds`、`transfer_seconds`、`local_verify_seconds`、`remote_recheck_seconds`：各阶段实测；无法拆开的阶段明确标组合计时。
- `retrieval_wall_seconds`：首次连接开始到所有取回校验结束的真实墙钟时间，包括退避/重试；`total_task_seconds`另含准备和交接。
- 文件数、未压缩原始字节、实际收到归档字节、重试次数和复用字节。归档字节/传输时间只能称接收有效吞吐，不能称包含SSH开销的链路带宽。无独立传输阶段计时就不编造纯网络吞吐。

成功条件是：批准范围内所有项目均有处置记录；应取文件集合、大小和SHA256完全一致，源稳定；必要结构检查有结果；计时口径和缺失/未验证项明确；无远端项目写入。无法证明远端无写入时如实写审阅依据及限制，不宣称全服务器零副作用。源缺记录可给“现存文件完整、质量材料有缺口”，不能把两者混成全通过。

## 交付

独占取回目录至少有 `RETRIEVAL_TASK.json`、`source/`（取回实现）、`raw/`（命令/错误/原始流）、`snapshot/`（解包原件）、`manifests/`（前/后/本地摘要）、`timing.json`、`coverage.json`、`verification.json`、`REPORT.md`、`status.json`。原件只读消费，分析或格式转换放另一个目录。报告列出完整性结论、文件数/字节、各阶段耗时、质量材料缺口与排除项、是否读过私有标签/执行计算或远端写入。

专用取回Thread是叶子执行者，亲自完成，不再派Agent、Thread或CLI模型。主控审读新增范围、原始证据和异常，消费实际覆盖回执；首次建立可靠性或有缺口/冲突时定向独立核验，不仅凭success认定通过，也不例行重跑整套检查。整批固定评分完成且来源核验通过即可回报分数；确有Pro请求才继续其材料与公开候选，不新建无消费者的归档尾单。

公开交付的成功条件是本次批准对象及必要入口可读、来源和内容相符；既有历史只引用固定版本。主控已知的本批导航与研究补件随候选准备，避免发布后再为小文件单派一轮。内容/身份回执已足以接续时先回报，完整耗时及记账随后补齐；不能为等最终报告而延迟下游。训练、评分、候选整理、推送和匿名读回的时间分开，不把整段称上传。v1.3.0对应[实际分段证据](../SOURCES.md#ref-268db8c51569eea7)，尚未验证新版全链路提速。

## 已验证范围与取回教训

2026-10-31 首次全新 Sol/xhigh 会话完成真实只读取回，主控独立复算通过：[验收记录](../SOURCES.md#ref-9f9f08dd32ba9f32)。302 文件、110.81 MB 原始数据，归档 44.11 MB；传输 66.97 秒，连接至字节校验结束 77.42 秒，全结构/范围检查结束 338.94 秒，整个执行会话 575.06 秒。批准范围内文件全覆盖，未记录的训练信息仍有缺口。实测仅覆盖该完成且稳定的 run、当前连接与约 111 MB 规模，不能据此保证所有规模、异常分支或全依赖环境可复现。实测时使用的 Skill 原文和摘要保存在该取回任务的 control，以下教训在终态验收后补入。

- 原 CSV 可能带 UTF-8 BOM；结构读取沿用原数据解析约定，不能把 BOM 误认成字段缺失，更不能为通过检查修改原件。
- 交付清单须在所有被收录文件的写入进程结束后固定；第一次自验曾因 finalize 的 stdout 仍在写入导致清单过早固定。修正衍生清单时保留旧版及原因，原始归档不变。
- 全任务计时应覆盖首次规范阅读；若计时标记稍后建立，标明下界，并用可信 Thread 起止记录补充完整会话时长。下载结束、全部检查结束和交付结束分别报告。
