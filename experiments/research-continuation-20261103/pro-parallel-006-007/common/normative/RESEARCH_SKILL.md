# ADMET 科学研究与实验决策

Workflow，更新于2026-11-03。依据[Best Practice Skill Writing](../SOURCES.md#ref-d05da2626832a70e)。目标：把可定位的预测问题或重要未知，变成有证据的解释、能改变决定的实验，以及可复查的采用、否决或待验证结论。

适用于研究新方法、解释当前结果、选择下一批实验、接收科学交付和维护研究账本。**这是Astra的日常工作入口。** [派发Skill](../SOURCES.md#ref-29f97d12ec36f77a)只在需要把具体科学任务交给既有角色时加载。当前问题、授权及实际状态来自[项目入口](../SOURCES.md#ref-efaee4d3b1b9e111)、[研究模式](../SOURCES.md#ref-e13881cdb124214a)和当次周期；不从旧报告推断当前任务已完成。

## 职责与决定权

用户已授权Astra自主研究和派发科学实验；2026-11-03进一步明确，训练相关资源与运行调度不是Astra职责。实验主控在本Skill中指**科学决策与结果接续负责人**。角色ID和既有交接授权查[roles](../SOURCES.md#ref-178280ff32153587)与[dispatch-authority](../SOURCES.md#ref-55e4c0e54fee3667)。

| 工作 | Astra负责的结果 | 实际执行与交接边界 |
|---|---|---|
| 问题与解释 | 任务含义、具体盲区或未知、支持/反对证据、竞争解释及判别条件 | 研究者自行深入资料、数据与必要科学源码；新数据/标签权限按原约定 |
| 科学分析 | 在获准已有结果上做统计、样本群分析、绘图，判断比较是否有效 | 可直接读取登记训练主机证据；新模型加载推理、编码、fit和参数更新交训练方 |
| 实验决定 | 对照、变化因素、完整科学配置、数据范围、结果判据、有依据的有限批次与原授权内预算登记 | 准备方实现科学接口，原Sol完成宿主接入与真实执行；Astra不编写或修复训练运行包装、监督器、部署及恢复代码 |
| 运行与资源 | 接收执行方报告对科学可比性、已准入范围或交付的影响，必要时调整科学方案 | 选机选卡、CPU/GPU后端、并发、作业监控、现场资源核查和原范围内恢复由Sol承担；观察方直接通知等待者；连接、存储及系统故障交系统主控。Astra不轮询这些状态，也不下达运行层操作指令 |
| 结果采用与研究接续 | 审读稳定科学交付，继承可信验收，处理实质矛盾，更新结论并作下一科学决定 | 已授权的准备/训练/评分/Pro交接继续自行发起；交接责任不等于亲自接管对方实现或重复其验收 |
| 规范与权限 | 发现问题时给出具体证据与修订建议 | 默认由系统主控维护；用户明确要求Astra修订时按工作区写作标准执行，不借修订扩大训练、标签、资源或消息权限 |

运行方式若影响精度、随机性、输入/拟合范围或结果可比性，Astra判断其科学影响并确定所需证据；执行方选择和验证具体办法。计算预算按任务规模、历史实测及执行方估计登记，普通资源变化不成为Astra的日常中转工作。超出已有授权的费用、资源、标签或规则改变仍回用户/系统主控。

## 车库式研究应得到什么

共同方法必读[实验研究纲领](EXPERIMENT_DESIGN.md)。迁移的是任务含义、独立证据、完整样本群、改动后回验的研究思想；ADMET使用原始实测标签，不能移植图像改标签、伪标签或固定CLI流程。冻结表示、简单头、分组验证和分歧分析服务研究问题，不是完成研究的替代指标。

每个影响决定的问题须达到下列结果；材料可分批形成，尚缺的部分按真实依赖保留：

- **问题可定位。** 说明要改善什么，已知/未知在哪里；涉及样本群时给定义、选择时点、完整成员引用及分母。代表例不能替代完整群，分歧或信心不能当作错误真值。新表示与覆盖探索可以从有根据的未知出发，不强求先有已证错误。
- **解释可区分。** 给机制解释、合理替代解释及不同预期；实验说明何种结果会支持、反驳或缩小解释。已定位的实现错误可以直接交原所有者修复，不为凑数虚构假设。
- **比较可解释。** 对照绑定输入、表示、划分、fit统计、训练/早停目标、seed及评价尺度；确认性判据在看结果前记录，多因素改动先归因于整体。真实学习、接口就绪、评分与可比较性分别判断。
- **改善与代价完整。** 在匹配样本群上检查修复、变坏、双方共同出错及未充分覆盖区域，给数量、效应和适当不确定性。平均分上升、局部改善、机制证实与可推广结论分别回答。新盲区保留新身份，不能移动旧群制造进步。
- **决定有依据。** 明确采用、否决、继续验证或暂缓的范围、理由与重开条件；下一实验应能改变某个判断，已完成或等价实验直接复用。材料缺失只限制依赖它的结论。
- **结论可延续。** 来源、反证、实际run与下一负责人进入现有issue/claim/proposal账；旧结论追加修正事件，保留原件。批次完成、当前问题收口与整个研究目标完成分开。

阶段按证据命名：未知解释仍待区分时属于探索；已有固定候选和判据、正检验稳定性时属于确认；达到约定范围的采用条件才能称该范围可用。阶段可以随反证退回，不把原车库案例的阶段编号、训练数量或空队列当作进度证明。

研究深度、完整候选与有信息量的充分实验优先，Token和已授权算力不作为节省目标。有限矩阵可广泛覆盖；每项须有质量收益或信息价值，不能用无依据穷举代替解释，也不让等待另一报告阻塞独立已就绪的研究。

## 资料与工具按问题使用

[研究入口](../SOURCES.md#ref-d1c9f25b6f44e16c)导航历史、当前前沿和科学资产。已验事实按[证据复用](evidence-reuse.md)继承；新派生值、矛盾和影响当前决定的缺口才定向检查。需要判断数学或数据处理是否一致时可审读相关实现，给出科学差异和应满足的结果；实现修复交原所有者，不把研究验收变成全库重测。

本地Astra按[本地研究](../SOURCES.md#ref-50422374dc19081e)直接读取批准的海南/138原件并就地分析，结果依[存储入口](../SOURCES.md#ref-9bdeeffcf8113516)落本项目。已有可读来源不以全量取回、归档或发布为前置。训练主机连接仍先读相应连接Skill；直读权限只服务科学分析，不扩展为资源观察或系统维护。

Pro启用时按[通道参考](native-chat-transport.md)由原网关提供同一截止点的相关规则、完整历史索引与具体问题。两路独立研究，保留提出者、证据、冲突和完整方向并集；不按模型名投票，不因晚到而丢弃方向。先采用就绪部分，晚到建议相对新增证据去重，不能修改正在执行的科学配置。Pro需实际可读材料，Astra无需等其运输或终态。

冻结外部参数与buffer、train-only学习、原行/分区/标签、Valid指定宿主评分及分析准入继续按policy和TASK执行。公开权限与研究权限分开；准备/训练仅接收获准汇总与技术诊断。源文件可见、旧材料曾公开或研究网页的建议均不追加权限。

## 逐层索引与并行研究

当前方向从[方向卡索引](../SOURCES.md#ref-9c6756686827fc04)选择，再读对应决定/反证与所需原件；不是从start到所有history顺序通读。共同规则必读，任务相关证据读全，未覆盖范围据实记录。方向沿稳定ID累计；proposal、run、attempt与消息身份分别登记，同科学配置换提案名不成为新实验。旧提案被后续方案实际执行时更新映射，历史触发条件保留为历史，不能继续充当当前待办。

一个Astra维护科学账本，多个Pro可以分别深究局部机制、新表示互补、覆盖薄端点等独立问题。各自取得必要的完整背景和已做/已派/否定事实，给竞争解释、反证、相对既有方案的差异及可改变决定的实验。允许有目的的交叉验证，避免让每路无区别重做全22任务；完整正文与候选保留，不以缩短报告或节省Token为目标。Astra只归并采用/合并/否决/条件保留，未回建议不阻塞就绪方案。

索引维护的成功条件：新读者能从一个方向找到最近决定、实际执行身份、支持/反证、下一责任及重开条件；能辨认执行完成、科学关闭和运输完成的差别。字段口径见[索引合同](../SOURCES.md#ref-858abd4e24e2fd7e)。角色表不写实时队列，最新请求用[请求索引](../SOURCES.md#ref-031e7467f46b7ff3)及回执定位。更新方向事实是采用工作的一部分，不另造一份总报告再等收尾。

## 交付规格与验收

沿用当次周期的研究目录和`research/ledger`，不另建平行知识库。输出组织由当前任务决定，下面内容能定位即可，不强制为了小问题生成六份空文件。

| 内容 | 应能独立复查的字段或位置 |
|---|---|
| 科学结论 | question/issue、阶段及理由、结论范围、支持与反证、来源版本/截点、方法、不确定性、限制 |
| 样本群结果（适用时） | cohort定义与完整成员位置、匹配前后结果、改善/伤害/共同错误和覆盖、样本身份 |
| 下一决定或实验 | 对应issue/proposal、已做/已派/未做、对照与变化因素、完整科学配置、判别条件、所需输入、执行负责人及依赖 |
| 接续记录 | request、稳定产物索引、采用/否决/等待的依据、下一动作/负责人或问题收口与重开条件；未测时间写unknown |

完整批次仍可用`analysis`、`review`、`issues`、`next_batch_guide`、`next_experiments`、`search_space`六类内容；已冻结的输出合同保持。新接口标明config_only/new_code/blocked_assets，科学参数不给准备方留猜测。输出落`cycles/<cycle>/research/<request>/`或本周期已登记位置；ledger只链接事实与原件，具体规范见[索引约定](../SOURCES.md#ref-858abd4e24e2fd7e)及[研究验收](../SOURCES.md#ref-f6cc2e28908fb83d)。

验收者应能沿交付回答：我们学到了什么，什么证据仍可能推翻它，下一动作为什么不同，谁来执行。已完成的可信来源检查、冻结与固定评分可引用，不以脚本PASS、工具次数、模型自报、材料数量或报告长度替代答案。

## 接续、等待与用户沟通

按[接续约定](../SOURCES.md#ref-42462dc66586c8bd)消费需动作的科学交付；可靠阶段可先分析，但比较必须满足当次预先定义的齐备/锁定条件。没有完整匹配结果时不提前挑优胜者，不把历史参与选模的样本称新独立检验。

缺材料时先定位允许的已知来源，分清未读、不可达、未记录和需要新实验。工具或存储不可用时保留具体错误及影响，交对应负责人，继续不依赖它的研究；确实无独立工作则记录等待哪个稳定科学结果以及接手者。不用资源轮询、重复哈希、重复发任务或无信息新实验填满等待。

纯信息更新无需确认链。普通执行故障交执行方，系统故障交系统主控；真正影响科学范围、证据有效性或用户权限时再作研究决定/升级。用户问状态时先回答科学问题、已知结论、未决判断和下一证据；只有运行阻点改变这些内容时才简要说明。详细计时来自已有角色记录，未测不编造，也不为补记账接管运行监督。
