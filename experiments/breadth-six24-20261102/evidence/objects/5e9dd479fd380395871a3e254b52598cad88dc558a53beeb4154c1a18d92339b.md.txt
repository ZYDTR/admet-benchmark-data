## 2. 零fit准备任务及验收职责

### G00-READ-BOUNDARY · 主控投影与数据权限

**责任**：主控生成角色最小化投影；准备方核对。**输入**：本指南、每task approved train.Y、盲valid/test输入身份、批准科学资产、必要代码与原模板身份；不发整个历史包含答案的包。**输出**：`role-input-manifest.json`，列源角色、hash、获准用途；敏感数据缺席断言和访问日志。

**保持**：原始行、标签、SMILES、顺序；禁止清洗/去重/伪标签/外部数据/test拟合。**验收**：valid/test输入只含blind列，非盲label路径不可访问；不跟旧公开答案链接；只从train拟合任何学习统计。**失败**：整批停止并交主控，不由准备方用公开链接补齐。零fit仅做只读元数据、数学合成fixture及少量批准输入的无参数更新检查，不做全量encoderforward。

### G01-ASSET-IDENTITY · 私有依赖与冻结接口

**责任**：准备方，主控独立核验。**输入**：上节批准weights/encoder身份、R16资产表、当前运行环境。**输出**：`asset-readiness.json`、依赖版本清单、源码diff、freeze/hash fixture、失败原文。

**变更**：在项目私有目录准备必要依赖与新task dispatcher；不修改他人环境/共享系统、不在未授权远程主机操作。**保持**：CheMeleon BondMessagePassing→原MeanAggregation→fingerprint语义，2048维；不加CLS/任意mean池化。所有encoder参数`requires_grad=false`，eval时buffers亦不得变化；optimizer仅包含head参数。

**零fitfixture**：使用已准入train中的极少量指定行，前后encoder state/buffer digest一致，输出shape(N,2048)、dtype与有限性符合合同；parse failure按已有政策保留零embedding和mask，不删行。构建head/optimizer检查参数ID交集为空；不执行optimizer.step。真实head非零更新与恢复后的训练等价，只能在未来获准训练时验收，不伪称准备阶段已有结果。

**失败/替代**：权重hash、代码版本或输入覆盖不一致则该资产blocked；不能临时换MiniMol/MoLFormer、换更大checkpoint或下载外部预训练数据。

### G02-INPUT-SPLIT-<task> · 数据身份与train-only分区

**责任**：准备方；数据身份由主控确认。**输入**：每条exact_config.inputs中具体train/blindvalid/test hash及行数。R19原来train per-file SHA未知，本次从既有SMILES统计原件的input_hashes登记了每task expected train SHA；准备方必须与实际批准train文件逐字节匹配，而非相信这个登记值即可。

**输出**：`input-check-<task>.json`、`split-manifest-<task>.json`、`train-profile-<task>.json`。列train/valid/test三种行数，split内row_index键唯一性，Drug_ID重复/空值，仅作诊断不删除。train.Y profile列dtype、finite、min/quantiles/max、分类counts、ties/constant；这些是待产生测量，不从valid标签汇总代替。

**split43确切算法**：按exact raw Drug字符串分组；唯一key按codepoint排序；CPython `random.Random(43).shuffle`；取完整groups直到≥max(1,round(0.1*n))，不得吃完所有groups；保留输入行序。Python round规则和版本写入manifest。分类当前不额外stratify，不能静默变算法。保存fit/stop row IDs、hash、具体n及train-fit/stop类别结构；实际group大小意味着n不一定正好90/10。

**验收**：fit∩stop为空、并集为全部train行，原SMILES group不跨分区；与外部blindvalid/test不混用；没有标签/行修复。任何一类缺失或排名目标常量导致指标undefined则fail task preparation，不能换seed直到好看。若需stratified-group重设计，主控登记新split_id，两边config都换后再审，不继续沿用旧对照。

### G03-METRIC-INTERFACE-<task> · 新代码的明确生产接口

**责任**：准备方实现，独立验收者用手算fixture对照。**输出**：`interface-map.json`、源码版本/diff、`metric-fixtures.json`、config schema校验结果。

旧Caco2严格runner公开验证了现有MSE/MAE monitor、缓存与恢复；没有证据它已接受全部分类/AP/Spearman字段。因此本批不是config_only。新interface_id是`admet-frozen-breadth-repair001-proposed`；`head.hidden_dims`、`optimizer.lr`、`optimizer.weight_decay`、`loss.name`、`early_stopping.metric/direction`等是拟议显式合同，不得把width/wd/“task-native”伪装成已有生产字段。适配器必须列每字段到真实实现的映射、允许值、拒绝未知字段策略；实际code hash准备后登记。

**固定生产语义**：
- head2048→256(ReLU,dropout)→1，bias=true，无BN/LN/residual，524801可训练参数。两config同seed初始化weights应相同；sampler独立CPU generator同seed，batch顺序一致。
- AdamW lr0.0005、weight_decay0.0001、betas0.9/0.999、eps1e−8、amsgrad=false、scheduler=none，所有head参数decay、encoder不入optimizer。
- batch128、max_epochs50、patience8、min_delta1e−7、earlier tie、每epoch评估、restore_best；float32/noAMP/no_gradclip、workers0、drop_last=false。Python/NumPy/Torch/CPU-CUDA seeds都绑定该run唯一model seed；strict deterministic若不支持则fail，不静默降级。
- 分类BCEWithLogitsLoss、target0/1、pos_weight1、mean，输出sigmoid(logit)连续正类概率，earlystop head.eval。BBB AUROC maximize，CYP2D6 Veith AUPRC字段按本地AP maximize。
- 回归MSELoss，target仅由inner_fit mean/std ddof0标准化，std0→1；导出逆变换恰一次。Lipo/LD50/solubility MAE minimize；hepatocyte Spearman maximize。原Y单位未证实不猜物理单位或再取log。

**必须通过的数学fixture（这些是定义测试，不是新的valid评分）**：

| fixture | 输入 | 预期 |
|---|---|---|
| MAE | y=[0,2,4], p=[1,2,1] | 4/3 |
| AUROC ties | y=[0,1,0,1], score=[.1,.4,.4,.9] | 0.875（平均秩） |
| AP ties | 同上，按相同score整组阈值 | 5/6；不得换梯形PR面积 |
| Spearman ties | y=[1,1,3], p=[3,2,1] | −sqrt(3)/2，平均并列秩 |
| sigmoid | logit=0 | p=0.5；不是阈值label |
| Y逆变换 | fitY=[10,12]→μ11/σ1，z_pred=2 | 导出13，不是2或24 |
| 常量feature | fit同值、std<1e−8 | 以1替代分母，不inf/NaN |
| undefined | one-class AUROC/AP或常量rank目标 | fail/明确undefined，不填0并继续 |

fixture误差容忍是数值实现测试（例如float64 metric1e−12、float32逆变换1e−6），不是未来模型收益阈值。该容忍可由实际dtype细化并登记，不能用它证明科学显著。

### G04-CACHE-EXPORT · 两层缓存与完整候选行映射

**raw cache**：checkpoint/实际encoder/featurizer/tokenizer/hash、输入原字节hash、task/split/row_index、raw Drug identity、dtype/feature_dim、parse mask；只存冻结表示。**scaled cache**再绑定split_id、inner_fit rows/hash、scaler算法/参数hash，不跨split误复用。Feature统计mean/std在inner_fit以float32/ddof0计算，std<1e−8→1；不使用valid/test统计，不裁剪特征或Y。

**零fit验收**：注入错误行序/丢行/错split/错featureversion必须触发失败；合法的重复Drug_ID和空ID必须依靠task/split/row_index正确回写，而不是删除或直接拒绝原数据；不能只看N×2048 shape通过。synthetic scaler测试和少量approved input回写验证raw与scaled路径；拟合统计的对象必须可审计。不要为了取shortcut将valid全量features计算混入零fit准备。

**模板**：官方template SHA `8ee41589d2c98e7b93081c058b3f928ac09bea4b3ffc899fa13677051e9baa20`，16379行，cols task/sample_idx/drug_id/smiles/y_pred/metric，BOM/CRLF。内部row_index与sample_idx基准显式映射，task+sample_idx唯一；Drug_ID不作主键。只写y_pred，其他单元/顺序/格式diff必须为空，分类范围[0,1]、回归连续finite、逆变换只一次。恒等模板fixture文件标`NOT_A_CANDIDATE`，不得用合成常数输出冒充模型预测。

未来仅训练六任务时，其余16必须接回已准入baseline的真实预测接口与身份，形成逐任务model lineage；无法核验任何任务则完整候选未就绪，不能人手补行。逐任务head装配≠seed ensemble≠joint multitask，三种方案的可训练共享部分和评价分别登记。

## 4. 预注册科学判据与后续分支

将改善统一为正数。MAE每seed `r=(MAE_H0−MAE_H1)/MAE_H0`；H0为0时不加epsilon，标该gate不可改善。其他metric每seed `d=metric_H1−metric_H0`。screen两个共同seed均>0，平均达到MAE相对0.01、AUROC0.005、AP0.01、Spearman0.03才具备候选资格。

这是**本修复的可证伪研究建议**，非已知噪声/业务阈值/统计置信度；来源是最新repair允许提出明确阈值，未冒充历史测量。报告0倍和2倍gate的敏感性，不在看结果后改规则以确保通过。inner_stop用于epoch与candidate选择有乐观偏差；外部official_valid若主控授权释放，保持config/规则冻结再据汇总复核。新seed仍不使valid独立。

**条件confirm**：从六task中最多2个，优先不同metric族，再按最差paired提升/gate、实际完整成本、task字典序破tie；选择过程由主控复核。双方H0/H1只追加seed46；44/45已有八fits不重跑。新增seed改善非负、三seed平均仍达到原gate方可保留为更稳定候选；仍不宣布独立泛化。条件任务未决定前只存`audit/conditional-followups.json`，不得用`task=TBD`混入精确next_experiments。

| 触发 | 主控可选动作 | 默认不做 |
|---|---|---|
| screen无候选过gate | 停dropout扩搜；查train-only scale/condition，审议DIR06/03/08 | 不自动上large或全84fit |
| 平均改善但seed方向不一致 | 记录不稳定；可单独批准双方seed46诊断或不追 | 不挑胜出seed，不声称通过 |
| LD50/solubility范围/结构风险持续 | 对照既有汇总查逆变换、scaler、featurizer；保留无环结构风险 | 不读取逐行valid残差，不裁剪/清洗预测 |
| 多task稳定改善 | 按上述规则最多两taskconfirm；之后另提uniform ensemble | 不额外调ensemble权重/用test反馈 |
