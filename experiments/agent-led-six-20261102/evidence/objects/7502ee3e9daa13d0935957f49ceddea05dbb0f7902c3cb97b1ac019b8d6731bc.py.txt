* the internal best-head selection and early-stopping metric is now chosen by config ``monitor``:
  ``internal_validation_raw_mae`` (original-scale MAE of inverse-transformed stop-group predictions)
  or the legacy ``internal_validation_standardized_mse`` path kept for compatibility checks;
  training loss remains MSE, both metrics are still computed every epoch under eval/no_grad and
  logged; best comparison uses ``value < best - MIN_DELTA`` (ties keep the earlier epoch);
* history rows carry monitor/monitor_key/monitor_value plus both metrics; checkpoint_identity binds
  each checkpoint's own epoch/steps/value and the true-MSE semantics of the legacy field name;

v4 changes vs train_remote_v3.py (single fixed config from source/config.json, no HPO):
* internal fit/stop split comes from training_science.split_train_stop_groups: explicit
  split_config (method raw_smiles_group_shuffle, seed, fraction), groups keyed by the RAW Drug
  string, codepoint-sorted keys shuffled by a dedicated random.Random(seed) (never global RNG,
  never model-init RNG); full row-index record + audit + source hashes are persisted;
* hidden_dims / lr / seed / dropout / optimizer / epochs / patience / batch_size are read and
  validated from config instead of hardcoded assertions about an old run's identity;
* every epoch logs standardized MSE + original-scale MAE/MSE for fit and stop under eval/no_grad

* best and last heads use their own epoch/step identity; full optimizer and Python/numpy/torch

* artifacts/train-predictions.csv adds per-row official-train predictions with fit/stop markers;
  artifacts/predictions.csv keeps the exact v3 schema and contains ONLY blind valid+test rows;

  fresh evidence only.

The module body performs no work: importing it never starts training. main() is the host entry.

def digest_state(model):
    each = {}
    aggregate = hashlib.sha256()
    kinds = {name: 'parameter' for name, _ in model.named_parameters()}
    kinds.update({name: 'buffer' for name, _ in model.named_buffers()})
    for name, t in sorted(model.state_dict().items()):
        value = t.detach().cpu().contiguous().reshape(-1).view(torch.uint8).numpy().tobytes()
        item = {'sha256': hashlib.sha256(value).hexdigest(), 'shape': list(t.shape), 'dtype': str(t.dtype), 'kind': kinds.get(name, 'state')}
        each[name] = item
        aggregate.update(name.encode() + b'\x00' + json.dumps(item, sort_keys=True).encode() + b'\x00')
    return {'sha256': aggregate.hexdigest(), 'tensors': each}

    def predict(model, features, mean, std, y_mean, y_std):
        a = np.where(np.isfinite(features), features, np.float32(0))
        a = (a - mean) / std
        out = []
        with torch.no_grad():
            for s in range(0, len(a), hc['batch_size']):
                yhat = model(torch.as_tensor(np.ascontiguousarray(a[s:s + hc['batch_size']]), dtype=torch.float32, device=device))
                assert yhat.device.type == 'cuda'
                out.append(yhat.cpu().numpy().reshape(-1))
        result = np.concatenate(out) * y_std + y_mean
        assert np.isfinite(result).all()
        return result
