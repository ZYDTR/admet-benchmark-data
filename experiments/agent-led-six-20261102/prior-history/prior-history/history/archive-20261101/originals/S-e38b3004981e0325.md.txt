## 独立行为场景

四个 Agent 均使用新会话，不继承编写/研究前情，仅得到项目入口和自然语言任务。没有提供预期路径、正确答案或修复说明。读取链由执行 Agent 报告；完整场景、结果摘要与观察保存在 [验证记录](training-guidance-routes.json)。

| 场景 | 观察到的结果 |
| --- | --- |
| 训练与验证都差，是否四维扫参 | 选择 experiment；读决策、诊断、搜索与总览；先设计训练链/观测检查，没有断言容量不足或编造 run |
| Atom/Bond 固定所有参数、一次分高就采用 | 选择 experiment；区分单配置对照与配套调参，提供有上限的计划、重复确认及结论范围 |
| 缺失填零、去盐去重、全量标准化、归一化描述符 | 选择 data-provenance 并按条件读规则与 ADMET 风险；识别缺失、结构语义、泄漏和外部拟合来源；没有下载训练资产或运行模型 |
| 同类数据方案，明确禁联网 | 只读本地资料，保留依赖版本未在线确认的限制；完成方案审查，没有联网、写入、下载或训练 |

首次数据方案提示没有禁止网页研究，因此其公开文档查询属于允许范围，不能记为“违反禁联网”。另设的离线场景明确包含该限制；两者不能混淆。两次数据方案审查包含主题关键词检索的额外命中，未全文加载所有历史文件；并非证明路由达到最少 token。

## 结论与未验证范围

- 本次四次只读场景支持：三类主要任务能找到对应参考；明确离线限制下仍能依本地证据工作。
- 这些是有限行为样本，不保证所有未来 Agent 都会遵守规范；外层工具权限仍须由宿主实施。

- 没有真实官方训练包、真实训练、自动搜索调度、GPU/容器实机隔离或官方得分验证。
- 没有新增或重跑全套运行器测试；此次未改运行器。此前 71 项工程测试的日期和范围保留在 [原验收记录](../validation.md)，不将其冒称为本次训练验证。
