# 证据反方审阅：哪些证据足以改变下一步决策

审阅日期：2026-10-30。审阅者：`research_evidence_skeptic`。范围：V1、三份专项研究报告、`fact_check.md`、规则初核与数据审计；原报告均未修改。

## 结论

**当前证据足以结束广泛的候选文献搜索，进入少量受约束的本地比较；但数据审计中有两项尚未进入研究判断的重要事实，必须在 V2 中补上。** 最关键的是验证集的结构分布：AMES 的验证集全部属于一个非空 Murcko 骨架，LD50 与 solubility 的验证集全部是空 Murcko 骨架，而这两项任务可解析的测试输入全部为非空骨架。另一项是部分多任务“未见分子”验证子集小到无法回答拟议问题，其中 CYP2C9 substrate 的未暴露子集根本没有正类。

这不是推翻“同任务非空骨架无交集”的计算；它说明**隔离成立与验证覆盖充分是两个不同条件**。当前没有模型运行结果，不能说已经发现了真实模型排名反转、性能偏差或比赛违规。

本次只保留三个问题，不为数量增加候选缺陷：

| ID | 性质 | 实际发现 | 对决策的影响 |
| --- | --- | --- | --- |
| E1 | 文档遗漏；已有输入事实经直接复算确认 | 验证骨架分布极端集中，且部分任务与测试输入的环结构组成完全分离 | 降低官方 valid 单独支持广泛跨骨架泛化、模型淘汰和任务级冠军选择的力度 |
| E2 | 文档遗漏；暴露分层的可估计性经直接复算确认 | 小任务未暴露子集只有 3–9 行；CYP2C9 substrate 为 0 正类 | 不能把“按暴露分层报分”自动当成检验未见分子迁移的有效方案 |
| E3 | 未来假设风险；非本赛已观察错误 | AP 与梯形 PR-AUC 可给同一组模型相反排名，官方实现仍未核实 | 首轮预测应保留，以便低成本做指标敏感性核验；暂不将细小 AP 优势提升为官方优胜 |

没有发现足以推翻主线程已经纠正的 MiniMol 预算、CheMeleon 冻结消融、TabPFN 版本区分等主张的新直接证据冲突。

## E1：无骨架交集没有回答验证集是否覆盖后续决策

### 直接证据与复算

固定数据提交：`0275588ac7a5d3df032ec7dc0794cab21dfcfeeb`。原证据为 `../data-audit/chemistry-audit.json` 中各任务 `roles` 的 `empty_murcko_rows` 与 `nonempty_murcko_scaffolds`。初步报告强调交集为零，但没有把下表的覆盖集中纳入选型解释。

本审阅重新读取全部 66 个 train/valid/test CSV，**从不读取 Y**，使用 RDKit **2025.09.6** 的默认 sanitized `MolFromSmiles` 与无立体 `MurckoScaffoldSmiles`，重新按行聚合。采用的是同一化学定义的独立重算，不是另一套独立身份算法。零环计数只作补充诊断，不用于恢复历史划分。

可复查的脚本：`scaffold_distribution_review.py`；完整结果：`scaffold-distribution-review.json`。结果保存 66 个源文件 SHA256、脚本 SHA256、22 个任务全部划分的空/非空骨架样本数、骨架种类数与最大类覆盖。

| 任务 / 划分 | 总行数 | 解析失败 | 空骨架行 | 非空骨架行 | 非空骨架种类 |
| --- | ---: | ---: | ---: | ---: | ---: |
| AMES train | 4,684 | 0 | 1,268 | 3,416 | 1,126 |
| AMES valid | 1,137 | 0 | 0 | 1,137 | **1** |
| AMES test | 1,457 | 0 | 0 | 1,457 | 449 |
| LD50 train | 3,970 | 0 | 0 | 3,970 | 1,206 |
| LD50 valid | 1,937 | 0 | **1,937** | 0 | 0 |
| LD50 test | 1,478 | 0 | 0 | 1,478 | 470 |
| Solubility train | 5,045 | 0 | 0 | 5,045 | 1,325 |
| Solubility valid | 2,940 | 0 | **2,940** | 0 | 0 |
| Solubility test | 1,997 | **2** | 0 | 1,995 | 621 |
| DILI train | 331 | 0 | 0 | 331 | 219 |
| DILI valid | 48 | 0 | **35** | 13 | 11 |
| DILI test | 96 | 0 | 0 | 96 | 80 |

AMES valid 的唯一非空骨架为 `c1ccccc1`。全部 66 个文件的相关计数与原化学审计逐项一致，源文件 SHA256 也全部相同。可解析输入中，空骨架状态与零环诊断没有不一致。

**边界：**空 Murcko 骨架是这种以环为中心的表示没有留下骨架，不能把全部空骨架分子当成一个共同化学家族；一个相同 Murcko 骨架也不等于分子输入完全相同。本结果不猜官方如何生成划分，也不能仅据分布差异声称模型效果一定偏高或偏低。

### 哪些结论因此降级

1. “AMES valid 有一千余行，因此足以稳定判断广泛跨骨架能力”不成立。它能提供该留出骨架内许多不同分子的效果证据，但没有直接观察其他留出骨架之间的表现变化。
2. “LD50/solubility valid 比其他任务大，因此主要只需处理较小的抽样误差”不完整。它们在这项环结构描述上与可解析 test 输入完全分离，不能用更多 valid 行或训练 seed 消除该覆盖缺口。
3. 当前官方 valid 的最好分仍是现有比赛协议内的选择线索，但单独凭它给编码器作普遍淘汰、宣称测试排序稳定、或宣布跨骨架泛化已验证，证据不足。

### V2 应改变的判断规则

- 数据审计同时报告**隔离、覆盖和分布组成**。至少保留样本行、重复分子、骨架种类、最大骨架覆盖及空骨架比例；不能只报告“无交集”。
- 对这些任务，若要把小幅 valid 优势升级为稳健优选，可在原 train 来源内增加预先固定的分子/骨架分组诊断，观察多个留出骨架上的方向是否一致；同时保留原 valid 的独立角色和原始成绩。该诊断不是重建官方 split，也不替代官方成绩。
- 若预算不允许追加诊断，就保留“只在当前 valid 分布上有优势”的结论，避免针对这几项任务进行大量冠军搜索或密集融合调参。无需为此暂停其他任务的数值基线。
- 对 AMES 做分子级重采样至多说明当前骨架条件下的样本波动，不能生成未观察骨架的变化；单一骨架的 cluster bootstrap 也不能解决这个信息缺失。

**收敛判断：**本项需要补的是治理规范中的覆盖判据和后续实验问题，不是更多论文检索。直接重算已足够支持此项修订。

## E2：多任务暴露分层并不总能产生可解释的未见分子指标

`../agent-reports/evaluation-mtl.md` 第 5 节已经正确区分目标标签泄漏、其他端点监督暴露与未见分子泛化，也建议必要时按是否在其他任务 train 出现进行分层。但原审计提供了行数，却没有给出未暴露子集的类别构成；在当前数据上，这个遗漏会让下一位 Agent 误以为分层一定能检验迁移原因。

本审阅从所有任务的原 train 读取原始 SMILES，仅从 valid 读取标签，未读取 test。对每个目标任务，查询其每条 valid SMILES 是否存在于其余 21 个任务的原 train。脚本为 `mtl_exposure_review.py`，结果为 `mtl-exposure-review.json`；22 个任务的暴露行数与原审计完全一致。

| 任务 | 原 valid 行数 | 出现在其他任务 train | 未暴露行数 | 未暴露正类 / 负类 |
| --- | ---: | ---: | ---: | ---: |
| CYP2C9 substrate | 67 | 64 | **3** | **0 / 3** |
| CYP2D6 substrate | 67 | 62 | **5** | **1 / 4** |
| CYP3A4 substrate | 67 | 61 | **6** | **4 / 2** |
| Bioavailability | 64 | 55 | **9** | **5 / 4** |

这仍是**原始字符串身份**的可见监督暴露诊断，不是对预训练语料的审计，也不是违规判定。

### 应采取的具体判断

- CYP2C9 的未暴露子集没有正类，不能从其 AP/AUPRC 得到有效的正类检索能力证据。即使软件返回 0 或约定值，也不能把该数字当成“模型对未见分子失败”的实证。
- 其余几个子集虽然有两类，也不能依靠几条观测把共享学习的增益分解为“可迁移表示”与“跨端点结构暴露”的确定原因。这里不是要求固定 p 值，而是报告该子集实际拥有多少可区分信息。
- 若任务确实要回答全端点均未见的分子泛化，应在获准 train 来源中预先定义全任务共同的分子隔离诊断，并检查每个评分任务的类别和骨架覆盖。若无法获得可估计子集，则保留问题未决，不通过更改官方 valid、混入 valid 标签或借助其他任务的分数补造证据。
- 原始多任务协议仍可用于衡量完整方案对官方 valid 的效果。结论应明确其条件，不因上述不足否定全部 MTL，也不重新质疑已确认的冻结权重规则。

**收敛判断：**不需追加 MTL 文献；把“先检查分层是否可估计，再决定能回答什么”写入 V2 即可。没有模型结果前，无须开展多任务训练来完成本轮规范交付。

## E3：AUPRC 实现未知应触发一个有限的决策敏感性检查

原报告已准确指出 [TDC evaluator 的 `assign_evaluator`](https://tdc.readthedocs.io/en/main/_modules/tdc/evaluator.html) 将 `pr-auc` 映射为 `average_precision_score`，而 [scikit-learn AP 定义](https://scikit-learn.org/stable/modules/generated/sklearn.metrics.average_precision_score.html) 区分了非插值 AP 与梯形面积。本审阅于 2026-10-30 直接复查了这两个一手来源；它们都不能证明赛方采用哪一种实现。

需加强的不是“继续提醒未知”，而是说明未知是否足以改变选模。下面是人工构造的同一组 5 个样本、2 个正类、无并列分数的反例，**不是本赛预测**。固定标签 `y=[1,1,0,0,0]`；A 的分数为 `[4,1,5,3,2]`，B 为 `[3,2,5,4,1]`。

| 预测 | 正类按分数降序的名次 | AP | 梯形 PR-AUC |
| --- | --- | ---: | ---: |
| A | 2、5 | **0.450000** | 0.287500 |
| B | 3、4 | 0.416667 | **0.291667** |

本地以 scikit-learn **1.8.0** 的 `average_precision_score`、`precision_recall_curve` 和 `auc(recall, precision)` 计算，结果如表。也可直接复核：AP 为各正类名次处 precision 的均值，分别为 `(1/2+2/5)/2=9/20` 与 `(1/3+2/4)/2=5/12`；梯形面积分别为 `23/80` 与 `7/24`。这证明排名反转是可能的，不证明本赛候选已经反转。

V2 可规定：先以清楚命名的 AP 作为本地参考；保留每行 valid 预测；当候选淘汰、优选或融合主要依赖 AUPRC 任务的小幅差距时，在相同预测上计算预先指定的另一合理实现，记录排名是否改变。只需这项有限检查，不应穷举所有指标变体或选择最有利的一个。若排名对实现敏感而官方仍未知，则收窄结论，继续其他不受影响的实验。官方总分未知也应保留逐任务结果与本地准则，而不是自造“官方分”。

## 哪些问题已经足以停止查文献

- MiniMol 的主用法贴近冻结迁移、CheMeleon 有真实冻结证据及反证、MoLFormer 有明确公开固定表示接口：现有原始材料足以让它们竞争有限 pilot 名额。精确首轮先后应由接入准备度、预算和研究问题决定；现有证据没有支持它们在本赛的效果排名。
- 简单指纹/描述符与从零训练深度模型作为对照已有充分理由。无须继续寻找论文来“证明简单方法必胜”或“证明预训练必胜”。
- KPGT 辅助资产、MolE 权重入口、Uni-Mol 构象/裁剪、TabPFN 版本及上下文语义已明确到可以 `defer` 或有条件试验；在决定真正启用某支线前，没有必要把所有分支的工程缺口全部补齐。
- MiniMol 的历史结构暴露审计应限制公开排名的可迁移性，但未证明本赛目标测试标签泄漏。现有材料没有理由因此重新询问已经确认的冻结权重许可，或下载 LargeMix 来扩展本轮范围。
