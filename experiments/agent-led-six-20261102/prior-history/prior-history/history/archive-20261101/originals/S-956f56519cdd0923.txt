# 独立接手决策审阅：哪些问题需要研究到什么程度

日期：2026-10-30。角色：接手项目的研究负责人。范围：只读本地 V1、三份专项报告、规则记录、主线程事实核验与审计产物；未浏览外部来源、未重新执行化学审计、未训练或下载模型/样本。以下模型文献判断是对已有研究证据的采纳与限定，不是另一份独立性能复现。

## 结论

**当前材料足以结束开放式候选发现，进入“少量候选、明确问题、有限比较”的阶段。V2 最需要补的是把未知项映射到受影响决策的规则，而不是再增加流程清单。**

我接受 MiniMol、CheMeleon、MoLFormer 有首轮研究价值，但不赞成把三者、所有头、多任务和融合一次性铺开。优先建立给定数值标签上的独立任务比较；先研究两种固定图表示，MoLFormer 保留为第三个具有明确新增价值的名额或替补。允许冻结权重已经确认，无须继续调查该总前提。[R1–R5]

我还会在写 V2 前处理一个已见的解释缺口：现有化学审计不只有“同任务非空骨架不重合”，还记录了 Ames 验证集集中在一个非空 Murcko 骨架、solubility 验证集全部为空骨架。它们限制的是验证结果能支持多广泛的泛化结论，而不是自动证明数据错了或必须重划分。[R7]

## 1. 我的候选选择与投入顺序

这里的排序是研究投入顺序，不是性能排名。实际硬件和可用工程时间没有实测记录，因此不编造 GPU 小时，也不把“轻量”作为已实测结论。

| 顺序 | 对象与当前决定 | 要回答的研究问题 | 何时减少或追加投入 |
| --- | --- | --- | --- |
| 第一优先 | 固定 Morgan/描述符与小型神经预测头；保留随机初始化 D-MPNN 对照 | 给定标签和划分下，简单特征已能达到什么水平？预训练增益是否超出架构和头本身？ | 深度对照优先覆盖大 CYP 任务及代表性小任务；不必在最初就给每个小任务同样广的搜索空间。最终比较需要说明实际覆盖范围。 |
| 第一批冻结候选 | CheMeleon 和 MiniMol | 两个预训练目标不同、冻结证据与可得资产较明确的表示，是否带来本包增益？ | 文献没有支持两者的本赛排名。CheMeleon 的资产许可记录更闭合；MiniMol 的冻结方法证据更直接。哪一个先进入执行，由当前资产闭合程度决定，不由 headline 决定。 |
| 条件第三名/替补 | MoLFormer-XL-both-10pct | 序列表示是否提供图表示没有的有效信息？是否具有有用的输入覆盖差异？ | 前两者接入遇阻，或固定图表示比较后仍有值得解释的弱项时进入。不能仅以“架构多样性”声称必有融合收益。 |
| 后置 | 同一冻结表示上的共享预测头 | 额外任务监督与可训练参数共享是否改善目标任务？ | 先有独立头结果和逐标签来源边界。若只复用固定向量、头彼此独立，不能说已证明多任务迁移。 |
| 后置 | 融合；固定表示配特定版本 TabPFN | 真实互补是否足以补偿复杂度？表示表现是否受头选择限制？ | 只有单路线结果和针对性假设后再进入；一次合理替代头能改变结论时可补，但不无限搜索直到某表示胜出。 |
| 暂缓 | Uni-Mol、KPGT、SMI-TED、MolE | 各有潜在价值，但当前缺少优先挤占有限投入的理由 | 按已有报告的构象/辅助资产/重复方向/权重来源问题设置重开条件；暂缓不等于能力差或违规。 |

依据：图表示报告 §§1、3、4、6，其他表示报告 §§4–7，评价报告 §§4–7。[R3–R5] 我与各分支报告的主要区别，是**不把每个分支各自合理的 pilot 相加为首轮总计划**。研究负责人必须在总预算下删减候选，并保留被删候选的重开理由。

首轮应先回答“表示是否值得继续”，采用少量跨任务一致且合理的头配置。若随后给不同表示选择不同头，回答的就是完整方案的效果；这两类结果可以都重要，但不能相互冒充。相同头也不意味着全部维度、容量、正则条件天然公平，应记录这些差异并限定归因。[R3 §3、R5 §7]

## 2. 知识缺口应该阻塞哪一步

| 未知或异常 | 现在应阻塞的决定 | 不应阻塞的工作 | 解除或收窄方法 |
| --- | --- | --- | --- |
| 标签单位、变换、正类生物学解释未全部认证 | 重复取 log、物理裁剪、翻转正负含义、合并 assay、以共同物理量解释不同回归头 | 按给定数值 Y、0/1 编码和固定划分训练独立任务基线；训练集拟合的数值缩放及原尺度评价 | 只有依赖这些语义的具体分支才继续查证；无法确认时保护给定标签并缩小解释范围。 |
| 官方 AUPRC 算法、总分公式未确认 | 声称与官方评分严格一致，或把自定总分称官方总分、据此宣称赛事冠军 | 明示使用 AP 的本地参考比较、保存逐任务指标、事前约定本地取舍 | 当 AP 与另一合理 AUPRC 实现会改变决策时才优先做敏感性分析；官方公式未获知时保留不可判定的总体取舍。 |
| MiniMol 权重许可材料尚不独立闭合；其他候选有资产缺口 | 对该具体资产宣称已完成最终采用资格核验 | 研究适配性、其他候选及简单对照 | 针对确切资产补齐来源与适用许可，不重问已确认的“允许冻结权重”。这不是我作出的法律禁用判断。 |
| 2 个 test 输入默认 RDKit 解析失败，另有 388 重原子输入 | 宣称某候选可完整自动交付；静默漏行或截断后称全输入可支持 | 在已覆盖 train/valid 上研究模型效果、其他任务的比较 | 接入阶段针对实际候选验证覆盖，预先定义可复核的全行输出策略；解析器诊断不能替代所有模型的执行结果。 |
| 跨任务 train–valid 分子重合 | “所有验证分子对整个系统都未见”的叙述；来源混乱的多任务标签合并 | 单任务基线；明确限定为利用各任务 train 标签的研究方案 | 保留逐标签角色；对需要未见分子结论的主张另做对应诊断，不默认删去其他任务训练样本。 |
| 验证样本少、重复测量、验证结构分布集中 | 用单次小幅领先升级为普遍优势；把重复行当独立分子；把更多 seed 当作全部不确定性的解决方案 | 有限候选筛选，描述性结果及失败分析 | 先写明目标是此固定 valid 的选模还是广义新骨架泛化。后者需要另外的支持；不强求所有探索结果都得到显著性证明。 |
| 无实测吞吐、显存和接入成本 | 承诺完成时间、宣布可部署、用文件大小代表显存 | 形成有条件 shortlist 与最低成本验证问题 | 首个接入探针应回答实际瓶颈；发现不适配便减少投入，文献不可能补出本环境速度。 |
| 用户镜像与官方原始包缺少独立来源链；模板 ID 有差异 | 宣称镜像已独立认证为官方原包，或直接把旧模板用于最终提交 | 使用用户指定固定快照开展研究 | 保持来源说明；最终导出使用已核验当前模板，只写 y_pred。此项已在事实核验中有继续路径。 |

依据：[R2、R4 §§2–5、R6、R7、R8]。原则是**未知项只能阻塞依赖它的决定**；已经有安全、忠实于输入的继续方式时，不能要求全表变绿才开展工作。

## 3. 审计中值得补进主报告的实质性发现

我直接从现有 `chemistry-audit.json` 抽取了以下字段，没有独立重跑 RDKit。因此这些是“现存审计产物的重新阅读”，不是新的化学验证。[R7：`tasks.ames.roles`、`tasks.solubility_aqsoldb.roles`]

| 任务 | train | valid | test |
| --- | --- | --- | --- |
| Ames | 4,684 行；1,126 个非空 Murcko 骨架；1,268 行空骨架 | 1,137 行、1,135 个 canonical isomeric 身份；**1 个非空骨架，0 行空骨架** | 1,457 行；449 个非空骨架；0 行空骨架 |
| Solubility | 5,045 行；1,325 个非空骨架；0 行空骨架 | 2,940 行；**0 个非空骨架、2,940 行空骨架** | 1,997 行；621 个非空骨架；0 行空骨架，另有 2 行解析失败 |

**观察与推断必须分开：**这些计数已在 JSON 中；“验证结构分布集中可能使选模无法代表测试或其他骨架”是由这些观察提出的风险，不是已观察到模型失败。空骨架也不能被当作一个化学上统一的共同骨架。

我建议先定向核对这两项审计的定义与少量原始结构，再把结果纳入选模结论范围。无需恢复赛方历史划分算法。即使验证分布特殊，官方 valid 仍有现实选模角色；不应未经依据重切后声称结果与官方协议相同。但如果要宣称“普遍跨骨架优胜”，Ames 这里的一千多行不能替代大量独立验证骨架，也不能靠多 seed 或行级重采样制造这类证据。[R7；推断]

这一点比继续增加模型更可能改变研究判断：**隔离性与代表性是两个问题。**“没有交集”足以回答部分信息暴露问题，不足以回答评测分布是否覆盖目标人群。

## 4. V1 真正不能独自帮助陌生 Agent 解决的事项

V1 的目标和基本边界合理，不能把它深调研前尚无具体模型信息当成错误。真正的问题是几条规则仍允许相反且都看似合规的选择。[R1]

1. **遇到单位未知，到底能不能训练？**V1 第七节要求语义不全时停止受影响的正式训练建议，却没有把“直接拟合给定数值”和“按生物学语义改标签”拆开。不同 Agent 可能一个全面停工，一个擅自 log；本轮评价报告已经给出更可用的判断，应进入 V2。[R1 §七、R4 §2]
2. **一个 pilot 是值得研究，还是已经可执行？**V1 状态表不能表达 MiniMol 冻结证据很贴合但权重许可材料仍待定、CheMeleon 资产更闭合但冻结性能有反例、MoLFormer 公开资产与 headline 不同的组合。无需发明更多状态，可并列“研究价值、采用条件、本赛实测支持”三个维度。[R3 §4、R5 §§4–5]
3. **何种结果足以升级 preferred？**“足够实测支持”没有说明对固定验证集、任务集合、搜索自由度和成本取舍的要求。它不足以防止小验证集上按端点挑偶然冠军。V2 应要求在看结果前写清主张范围、比较对象和决策改变条件；不要求统一 p 值门槛或统一种子数。[R1 §七、R4 §4]
4. **跨划分无重合后，证据是不是已足够？**V1 关注重复、泄漏和划分来源，但未明确隔离性与覆盖性分开。现在 Ames 与 solubility 的已存审计结果构成补这条的真实理由。[R7]
5. **多份正确的分阶段文件，哪一份代表当前已知？**`dataset-audit.md` 边界仍写未安装化学工具、未建立化学有效性；后续 `chemistry-audit.json` 和 `fact_check.md` 已提供 RDKit 结果。前者作为历史字节审计没有错，但陌生 Agent 只读它会低估当前证据。V1 要求版本，却还缺“核心结论采用哪一版、旧边界被何种新证据推进”的轻量入口。[R2、R6、R7]

上述是文档可用性的实际缺口；尚未观察到后续 Agent 因此真的训错或提交错，不能把风险写成已发生事故。

## 5. 最重要的五项文档改进

| 改进 | 写入核心规范的稳定原则 | 本轮附录提供的具体实例 | 验证陌生 Agent 是否学会的方法 |
| --- | --- | --- | --- |
| 1. 决策依赖表 | 每个未知列出受阻决定、仍可做的事、改变决定所需最低证据 | 单位、AP/官方 AUPRC、2 个解析失败、权重材料 | 给出 Caco2 单位未知场景；应允许原值基线、暂缓语义变换，不能全面停工。 |
| 2. 性能证据绑定比较对象 | 一条性能主张绑定资产、更新参数/状态、数据、头、搜索与选择方式；可运行和强性能分开 | MiniMol 集成预算；CheMeleon 冻结反例；MoLFormer full-XL 与 10pct | 混给论文排名和另一个 checkpoint，应拒绝继承分数，并说明仍可支持 pilot。 |
| 3. 从反例决定下一检查 | 只补能改变当前决策的检查；一个头失败可触发一次有理由的头诊断，不触发无限救模型 | CheMeleon 冻结 FNN 与固定表格头前作 | 让 Agent 在继续查头、扩大模型名单、停止之间选择，并写改变选择的证据。 |
| 4. 明确结论范围与选模不确定性 | 区分固定划分表现、跨分子/骨架泛化、优化波动、样本覆盖和选择偏差 | 小 valid、重复测量、Ames 单骨架、solubility 空骨架 | 应保留官方比较并限制泛化结论；不能用“多跑几个种子”回答所有风险。 |
| 5. 设置薄的当前决策入口 | 主规范保留原则；一页入口说明当前采用版本、候选名额、未决项及可继续行动，链接最小必要材料 | 旧字节审计与新化学审计的范围推进；条件 shortlist | 无前情 Agent 不读全部来源档案，也能回答先试什么、为何、何时停止/重开。 |

V2 不需要把以上内容转成命令顺序、必须生成的十几种表或每一步审批。复用的对象是判断关系；模型名、数字、路径与软件版本应留在案例和候选材料。

## 6. 本轮停止调研与未来重开标准

**现在可以停止：**继续泛搜“是否还有更先进 ADMET 模型”、继续整理已无法直接迁移的排行榜、追溯不改变 shortlist 的所有前作。三份报告已覆盖足够多的互补路线，并已有真实不利证据；继续增加模型更可能增加选择负担。[R3 §§1、7–8，R5 §§6–9]

**交付 V2 前应完成的最小收尾：**把当前比较协议和候选优先级收敛为一份，明确各未知的阻塞范围；定向核对 Ames/solubility 审计含义；让当前证据入口消除历史审计边界的歧义。这些是证据整合，不需要模型训练。

**进入执行后才回答：**输入覆盖、载入完整性、实际吞吐、本包性能、头的真实影响、多任务与融合增益。不能为让调研“完整”而把这些未运行结果写成已知，也不能因为它们未运行就宣称文献研究永远未完成。

**重开一个分支的充分理由：**当前两条路线无法完整覆盖输入；成本超出实际预算；某任务出现可复核且现有表示不能解释的弱项；后续性能/规则证据改变候选排序；官方评价实现使已有选择发生实质变化。仅有新论文、更多参数、新版本或一次验证最好分不够。

每次追加研究应先回答：“哪两个当前可选行动，会因这项新信息选择不同？”答不出来，默认停止。停止允许保留未决结论；它不等于所有任务都已找到赢家。
