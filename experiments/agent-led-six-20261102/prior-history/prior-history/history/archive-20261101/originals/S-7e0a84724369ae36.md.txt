# HANDOFF — ADMET data-eval preparation (no training)

Role: leaf executor. Nothing here trained a model, ran inference, or touched an
optimizer. The main controller owns training/execution.

## Command contract (all relative to this `data-eval/` directory)

Scripts resolve `input/...` from their own package root (`common.PACKAGE_ROOT`),
so they work from any cwd. Run them from the task root to keep paths readable.

```bash
# 1. Verify inputs + template integrity (exit 0 ok / 2 contract fail / 3 internal)
python3 output/scripts/verify_data.py \
  --schema output/admet_eval/task_schema.json \
  --report output/reports/verify_data_report.json

# 2. Record per-split row counts + hashes (completeness source for scoring)
python3 output/scripts/make_split_inputs.py \
  --schema output/admet_eval/task_schema.json \
  --out output/reports/split_inputs.json

# 3. Score. Labels are ALWAYS passed explicitly. --split names the split the
#    predictions cover; completeness is checked against split_inputs.
python3 output/scripts/score.py \
  --predictions <preds.json> \
  --labels-json <labels.json> \
  --schema output/admet_eval/task_schema.json \
  --split-inputs output/reports/split_inputs.json \
  --split test \
  --out output/reports/score.json
#  or: --labels-csv <file.csv> --labels-csv-task <task> --labels-csv-split test

# 4. Export submission (byte-faithful y_pred replacement, refuses overwrite)
python3 output/scripts/export_submission.py \
  --predictions <preds.json> \
  --output output/submission.csv \
  --schema output/admet_eval/task_schema.json
```

Prediction JSON: `{"schema_version":1,"predictions":[{"task","split","row_index","y_pred"},...]}`
Label JSON: `{"schema_version":<C.LABELS_SCHEMA_VERSION>,"split_id":..,"labels":[{"task","split","row_index","y"},...]}`
