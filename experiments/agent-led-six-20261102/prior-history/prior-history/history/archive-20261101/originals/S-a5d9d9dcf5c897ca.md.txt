# ADMET Agent Harness — PRD

状态：工程交付；比赛训练数据尚未接入。日期：2026-10-28（Asia/Shanghai）。

## 目标

让三人团队的新 Agent 只从 `AGENTS.md` 进入，就能发现当前状态、选择任务技能、执行受约束的工程动作，并留下下一次会话能恢复的证据。项目面向兴智杯赛题 159 的工程与 Agent 负责人。

## 本次交付的成功标准

- 一个薄入口和一个技能索引；具体规范按需读取；没有孤儿技能和失效内部链接。
- 官方规则、公开模板观察、团队默认和未决问题分开保存并能追溯来源。
- 正式训练输入缺失、来源待审、哈希变化、任务定义未确认或运行环境不足时，报告具体阻塞；不下载外部替代数据。
- 提供可执行的状态恢复、数据核查、隔离运行计划、提交校验和证据打包入口。
- 原始模板所有非 `y_pred` 字符串保持不变；空原始 ID 合法；分类 confidence 与 probability 分别处理。
- 运行记录关联数据、代码、配置、环境、权重和预测；推理复现与训练复现分开报告。
- 通过行为测试和无前情 Agent 路由验证；记录真实通过、失败和未运行的部分。

## 边界

本次建设工程 Harness 和项目内工作技能。未授权发布公共仓库或上传比赛预测；交付为本地版本化项目。不安装全局个人技能。尚无报名后训练包，不能承诺训练 schema、模型成绩或官方总分。合成夹具只测试工程行为，永不准入正式训练。

## 团队责任

A（用户）：执行环境、Agent 工具权限、运行记录、复现与提交工程。B：官方数据、标签解释、划分与逐任务评价。C：深度模型、训练适配器和实验假设。每人可并行工作，共用同一份已确认的数据及评价契约。

## 需求分级

当前必需：渐进路由、状态持久化、数据和代码可追溯、正式训练失败关闭、提交正确性、独立验收。接入后必需：实际模型适配器、依赖锁定、容器集成测试、最终方案重训。暂不需要：常驻服务、向量数据库、自动浏览器上传、复杂角色编排平台。
