# 冷启动只读选型答复

日期：2026-10-30。范围：仅依据项目当前资料进行离线研究；没有联网、运行模型、训练或重算数据审计。以下性能和数据事实均指项目留存的证据及其明确版本，不表示本次重新复现。

## 一、给用户的回答

**我的决定是：CheMeleon 进入首轮有限试验，状态为 `pilot`；现在不批准它包办全部 22 项任务，也不把全部实验预算集中给它。** 保留简单结构特征和从零训练的小型 D-MPNN 对照，优先比较 CheMeleon 与 MiniMol 两条冻结表示；MiniMol 资产条件未闭合时，由 MoLFormer 的指定公开资产替补。最后允许逐任务选择，也允许同一方案覆盖多项任务，但要由本次数据上的结果支持。

这不是说 CheMeleon 已被证明较差。项目尚无真实比赛模型结果，没有候选达到 `preferred`。我反对的是把“论文成绩好”直接推成“本赛冻结条件下全部任务最好”，再据此取消对照。当前研究已足够支持有限实验，继续扩充模型名单的价值较低。[1][2]

### 1. 为什么论文成绩还不足以支持全押 CheMeleon

**首先，训练协议不同。** 项目对 CheMeleon arXiv v2 的核查指出：主表主要采用微调；kNN probe 也是先微调、后抽取表示。这些结果不能作为“原始外部权重自始至终冻结”的性能证据。赛事的已确认条件是外部预训练权重允许使用、但必须冻结；无需重新向用户确认这一点，也不能把它扩大成对额外数据、标签或任意外部拟合参数的许可。[2][3][4]

**其次，直接冻结的证据既有风险，也有积极线索。** 项目已找到 Research Square 附件 S5/Fig S6 中的永久冻结消融：在作者所用 FNN 和验证设置下，回归较弱，分类收敛行为也有变化。这使“冻结 CheMeleon 在九项回归都能直接继承主表优势”成为必须检验的假设。然而，这只是特定预测头和协议下的反证；后续不同团队使用固定 CheMeleon 与 TabPFN 2.6 的研究，说明换预测器可能改变结论。不能由一项消融永久否定表示，也不能由后作的统计 win 比例宣称本赛胜率。[2，§3、§6][3，M03、M05、M11]

**最后，成绩属于完整方案。** 有效比较必须同时固定或说明资产版本、输入处理、数据及划分、参数更新时间线、预测头、搜索与集成预算、指标定义。换 head、增加搜索、做集成后获得的提升，只能先归于整套方案。项目所读 arXiv、Research Square 附件与已发表期刊版也有版本边界；本次离线研究不声称它们逐字一致。[2][3][5，§3]

支持 CheMeleon 首轮试验的理由仍然充分：它有明确的固定向量入口，具体权重记录和许可元数据较清楚，且与现有 Chemprop/D-MPNN 路线接近。但发布方文件信息不是本地下载校验，接口存在也不是本批数据已全量跑通。[2，§3]

### 2. 本次数据决定了不能只看一个总分或一个种子

实际是 22 项任务、53,695 个训练标签行，其中 13 项分类、9 项回归；四类评价为 AUROC、AUPRC、MAE 和 Spearman。它不是每项任务都有五万多独立分子的数据集。三个 CYP inhibitor 任务贡献约 49% 的训练标签，统一按所有标签平均 loss 会隐含很不均衡的任务权重。[6，§2、§5]

最影响选型可信度的证据如下。

| 已留存的数据事实 | 对本轮选择的影响 |
| --- | --- |
| Ames valid 有 1,137 行，但非空 Murcko 骨架只有一种；test 有 449 种 | 现有 valid 上的提升不能直接证明广泛跨骨架优势。 |
| LD50 和 solubility 的 valid 分别有 1,937、2,940 行，全部为空 Murcko；train 与可解析 test 均为非空 | 样本行多仍存在结构分布差异；空骨架不能当成一个有意义的共同化学家族。 |
| DILI valid 仅 48 行、13 个数值正类；一些 CYP substrate valid 只有 67 行 | 小幅胜负可能很不稳定；多个种子不能补足验证样本和化学覆盖。 |
| PPBR、clearance 有同一 SMILES 的不同回归标签，BBB 有同输入 0/1 冲突 | 不默认去重、平均或删行，也不把 tiny-fit 必须零损失设成普遍标准。 |
| 默认 RDKit 解析失败两条 solubility test 输入，另有一条 388 重原子输入 | “支持 SMILES”不等于完整可交付；解析、元素编码、长度与回退需要逐方案验证。 |

这些是项目按固定数据版本和化学定义保存的审计结果，本次没有重算。它们限制结论范围，不证明模型排名已经反转，也不授权擅自替换原 valid。[6，§3–§7]

首轮共用冻结编码器、训练各自独立的 22 个头，应称为表示复用。如果要增加共享的可训练部分再研究多任务学习，需要与同一表示的独立头比较。跨任务 train/valid 有相同分子，不自动等于目标标签泄漏，但必须保留每个标签的 task/split/row 来源；不能把 valid 标签拼进训练。特别是 CYP2C9 substrate 未在其他任务 train 出现的 valid 子集只有 3 行、没有正类，不能用该子集的 AP 数字证明未见分子迁移成功或失败。[6，§5]

### 3. 候选决定与预算边界

| 路线 | 当前决定 | 首轮要回答的问题 |
| --- | --- | --- |
| Morgan/基础 RDKit 描述符 + 合理监督模型 | 必留对照 | 复杂冻结表示是否在简单结构信息之外带来可重复增益？ |
| 从零训练的小型 Chemprop D-MPNN | 必留深度对照 | 本任务表示学习是否优于冻结表示；冻结限制的实际代价是什么？ |
| CheMeleon + 新训练头 | `pilot` | 原始权重全程冻结后，在分类、回归和不同验证分布上是否仍有效？ |
| MiniMol + 新训练头 | 条件化 `pilot` | 与冻结迁移更直接对应的预训练方式是否优于 CheMeleon/简单特征？权重授权、加载完整性与覆盖先闭合。 |
| MoLFormer-XL-both-10pct + 新训练头 | 替补；有额外名额时为第三候选 | 序列表征是否提供有效增量？不能继承 full-XL 微调成绩；固定准确资产及 tokenizer/代码。 |
| CheMeleon + TabPFN 2.6 | `defer`，有机制依据时做组合对照 | 更换预测器是否能改善已显示潜力的表示？先处理精确版本、许可、资源，以及本赛新深度训练交付由什么模块满足。 |
| Uni-Mol/Uni-Mol2、KPGT、SMI-TED、MolE | `defer` | 由几何增量、现有表示不足或资产条件改善等具体证据重开，不占首轮主预算。 |

这是投入顺序，不是性能排名。MiniMol 论文也有搜索、集成与预训练暴露相关限制，不能换一个名字再照搬 headline。MoLFormer 的预训练去立体信息、长度限制，以及几何路线的构象和裁剪成本，同样需要按指定版本核对。[2][3]

在硬件与总时长未知的情况下，我不给虚构的 GPU 小时。采用全队统一的名额和阶段上限：**首轮最多两条冻结表示，配两类必要对照；一个基础预测头，只有出现明确理由才增加一个备选头；不同时铺开更多模型家族或大规模超参数搜索。** 给基线合理的训练和正则配置，记录实际可训练参数量、搜索次数、接入和推理成本。同样的 head 名称不代表参数量或优化难度完全相同。

### 4. 下一轮研究安排

以下均为待执行计划，本次不启动。

#### 阶段 A：把有限比较变成真正可运行的协议

固定数据提交 `0275588ac7a5d3df032ec7dc0794cab21dfcfeeb`，保留既有 train/valid/test 和原数值 Y。单位、历史变换、生物正类语义尚未完全确认，仍可设计原 Y 基线；暂不额外 log、按物理阈值裁剪、反转标签或合并 assay。数值 1 是当前分类评价的明确正类约定。[4][6]

完成实际适配器、固定本地镜像、正式数据登记和冻结资产接口后，才能进入项目正式运行；现有执行器只实现 random 初始化，不能因为政策许可就假设冻结资产已接通。正式运行前按项目要求通过 `check-data` 和 `plan`。这些是执行前置条件，不阻止现在把选型与评价计划写清楚。[1][4][7]

对精确 checkpoint、配置、依赖、代码和许可作登记，核验外部参数从加载到最终预测始终不更新；同时检查优化器对象、模型 buffer 和输入随机性。拟合型预处理仅用相应 train，test 输入可用于固定变换与覆盖检查，不能用于拟合 scaler/PCA 或选模。当前官方模板保留全部 16,379 行及非预测字段原字符串，预测回填只写 `y_pred`。[4][5][6]

覆盖工作优先定位两条 RDKit 失败串、长分子、多片段、立体信息和元素类别。任何程序化处理或回退都进入方案记录、保留行映射，并在其支持范围内验证；不静默截断或删提交行。缓存按清晰定义的输入身份复用，监督行不因缓存共享而合并。[5][6]

#### 阶段 B：先做能区分假设的 8 任务初筛

简单特征对照尽量覆盖全部 22 项；两条冻结表示与小型 D-MPNN 先用下列 8 项控制成本：

| 任务 | 选择理由 |
| --- | --- |
| cyp2d6_veith | 较大分类任务，AUPRC、类别不均衡。 |
| bbb_martins | AUROC，存在同输入冲突标签。 |
| caco2_wang | MAE，小规模回归。 |
| ppbr_az | MAE，重复测量/标签冲突显著。 |
| clearance_hepatocyte_az | Spearman，重复测量与排序目标。 |
| ames | AUROC，单骨架 valid 的解释限制。 |
| solubility_aqsoldb | MAE，valid 结构分布差异及测试输入覆盖。 |
| dili | AUROC，极小且结构集中的 valid。 |

使用同一数据角色、评价实现和有限搜索预算，保存逐行预测。先以单种子检查大差异和运行问题；只对可能改变选择的入围配置追加两个种子，使其有三种子结果。多种子主要评估训练随机性，不充当总体泛化保证。八任务筛选不能写成已经在全部 22 项胜出。[5][6][8]

官方聚合式和 AUPRC 细节未知时，逐任务报告 MAE（越低越好）及其他指标（越高越好）；本地使用 AP 就明确称为 AP。不把不同量纲加成所谓官方总分。只有当 AUPRC 的微小差异会改变去留时，才在同一组保存预测上做事先指定的有限实现敏感性检查；若排名依赖实现，降级结论。[4][6]

对 Ames、LD50、solubility 等决定性差异，补充一个预先约定、只在获准 train 内建立的分组诊断，同时保留原 valid。诊断定义不得由模型胜负反向挑选。预算不足时明确限制结论，不以更多 seed 或行级 bootstrap 代替未覆盖的化学结构。[5][6]

#### 阶段 C：有证据才追加共享、换头或融合

某表示在基础 MLP 下弱，但存在预先指出的机制或直接前作，允许一个有理由的替代 head；结果仍无增益且无误差互补，就暂缓该配置/分支，不无限续费。

共享学习只针对明确的小样本假设开启：同 encoder 的独立头为对照，标签逐项 mask，显式控制任务采样与 loss 权重，并检查逐任务负迁移。融合要求两个单模型本身有用且有实测互补；先用预先约定的简单组合，不在 DILI 的 48 条 valid 上密集搜索权重。

#### 阶段 D：入围方案补全 22 项并决定资源倾斜

在每个任务完成相同口径的比较、全行覆盖、成本实测和复现记录后，才决定最终分任务选用哪套方案。简单传统模型可承担科学对照；最终方案仍须明确满足赛事的“设计并训练深度学习模型”要求。调用完全固定的表格基础模型不能自动等同于完成了这一要求。[4][8]

三人的协作围绕问题闭环分工：一人负责必要基线与评价底座；一人负责两条冻结表示的受限对照；一人负责输入覆盖、结果复核和有触发条件的序列替补。各自完成训练、评价和解释，共用同一协议；不是每人无条件开一个模型家族。[8]

### 5. 什么证据足以改变我的决定

| 新证据 | 我会怎样调整 |
| --- | --- |
| CheMeleon 在精确资产全程冻结、同数据/划分、合理且有记录的预算下，对适当基线和另一冻结表示产生可重复、实际有意义的收益；关键验证诊断方向相容，覆盖和成本也通过 | 把它升级为对应任务的 `preferred`，将更多后续预算给它。 |
| 入围后补齐全部 22 项，CheMeleon 在预先登记的逐任务容忍线内均无实质损失，整体收益/成本有利，且无需为少数任务付出大幅牺牲 | 接受统一采用 CheMeleon 作为工程选择。容忍线在看比较结果前确定；不能事后调整成刚好获胜。 |
| 优势只出现在部分任务、单个种子、单一验证分布或更多 head/集成预算下 | 仅升级对应任务或完整方案；保留分任务选择，不声称编码器普遍胜出。 |
| 在合理基础头及一次有依据的配套对照后，CheMeleon 持续不如基线，且无实测互补，或覆盖/运行成本明显不合适 | 降为 `defer`，停止该轮追加预算；结论只覆盖实际测试的资产、head 和协议。 |
| 原始冻结表示有信号，而另一个 head 的受控对照可靠改善 | 重开预测器选择，比较整套方案；不因基础 MLP 失败永久排除表示。 |
| 明确证据表明当前方案更新了应冻结的外部权重、使用了未获准输入或不满足硬性许可条件 | 排除该具体方案直至修复；不以论文高分抵消规则条件。 |
| 其他候选的资产或接口长期阻塞，时间只够一条冻结路线，而 CheMeleon 可接入 | 可以先交付 CheMeleon 加必要对照，这是资源约束下的实施优先级，尚不是精度最优证明。 |

最强的反对我当前安排的理由，是并行多条表示会消耗接入和交付时间，而 CheMeleon 的具体资产证据较清楚。因此我把首轮冻结名额压到两个，替补不自动增加名额；如果对照已足够清楚地回答问题，就尽早停止支线。保留对照的目的，是避免把所有剩余预算花在无法继承的论文成绩上，而不是长期维持平均分配。

**本轮停止广泛文献搜索。** 当前最关键的未知已是“在这批数据和允许的冻结协议下效果如何”。离线材料足以作上述条件化决定；新增规则或数据版本、资产与覆盖反证、关键本地结果，才触发定向重开。没有本地结果之前，维持 CheMeleon 为 `pilot`，不写成已获胜或已失败。
