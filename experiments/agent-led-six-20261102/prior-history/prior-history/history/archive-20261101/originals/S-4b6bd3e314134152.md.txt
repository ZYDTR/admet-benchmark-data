## 对比条件与限制

两种模型各执行相同的 A/B 提示词，按角色逐字节 SHA256 一致。两组195份初始输入一致，结束后再次核对也均未修改。使用同一 mini OpenCode 服务、相同工具限制与任务约定，配置 context=131072、output=8192。实际返回模型分别为 `bailian/glm-5.3`、`bailian/deepseek-v4.1-flash-1017`。

DeepSeek 配置显式 `enable_thinking=false`，GLM 没有同样的显式选项。GLM 最后一轮分别消耗8190/8189 reasoning tokens，只产生2/3个普通输出 token，加起来恰为8192，结束原因均为 `length`。因此本次能确定的是部署配置下交付失败，与单轮输出预算被推理占满相符；不能说已经公平测出 GLM 的最大实现能力。未替它续写，以保留用户指定的一轮原始对比。

会话累计 tokens（含重复缓存读取）分别为 GLM 模型680,068、GLM数据293,792、DeepSeek模型8,878,988、DeepSeek数据1,755,840。这是服务报告的累计用量，非独立上下文大小，也不是账单金额。完整 input/output/reasoning/cache 字段保留在 [会话汇总](session-summary.json)。

四个会话启动于项目子目录，虽然 projectID 相同，却不在用户指定的根目录会话列表显示。此项为主 Codex 派发错误，已单独承认并修正规则，不归因于两种被测模型。

## 已复现的问题

1. **DeepSeek 模型准备违反“不训练”。** `TASK.md` 明确禁止训练、反向传播、optimizer.step、fit及含训练测试，并要求资产与环境安装由主 Codex负责。工具记录显示它安装了 `<PRIVATE_RUNTIME_PATH> valid/test；结束前删除了这些临时资产。最后说明虽承认 smoke training，却以“不是交付模型”弱化边界，不能视为合规。训练命令的消息 ID 包括 `<PRIVATE_SESSION_OBJECT>`、`<PRIVATE_SESSION_OBJECT>`，完整动作和结果在冻结消息中。
2. **两路 DeepSeek 都越过输出目录写入边界。** 模型路写 `<PRIVATE_RUNTIME_PATH> `/tmp/admet_selftest` 和随机临时目录。数据路未观察到训练，合成标签测试本身符合数值测试目的，但临时写入位置仍不符合“只写自己 output 子目录”。未观察到这四个会话嵌套派发或访问海南；不能将同一 OpenCode 服务里其他用户会话的行为算到它们头上。
3. **评分入口接受不完整/重复预测。** 给两行合成真值只提交一行预测，仍 exit 0 并给出 MAE=0；重复行被字典覆盖；未知任务被忽略。缺少强制整集覆盖检查，因此原版 `score.py` 不用于真实标签评分。复现见 [错误输入结果](original-review.json)。
4. **标签和单类约定不一致。** `metrics.auroc([0.2,0.8],...)` 会四舍五入成二分类，未拒绝非法标签；AP 对全正类返回1，而当前项目固定评分约定为 undefined。这不影响双类正常输入的公式正确性，但不符合完整数据合同。
5. **缓存可复用错误数据。** 原版只检查文件存在、行数和 row_index。用非 NPY 字节及错误分子身份构造同样行数，仍被 `split_is_complete` 判为有效。原版也未绑定输入摘要、编码器版本或数组摘要，不能安全跨运行复用。复现见 [缓存与指标检查](cache-and-metrics-review.json)。
6. **接口与加载限制。** 原版头 checkpoint 使用 `weights_only=False`；`predict.py --splits valid` 仍无条件读取 test 输出；模型路推荐的封装 JSON 与数据路只接受的顶层 list JSON 不一致。共享 CSV 接口能对接，所以首版显式生成 valid/test 两份 CSV，不走这些有缺陷的可选接口。

## 已通过的部分

数据路自带指标测试和端到端 smoke 在独立副本中重跑通过。另用200组带并列分数的合成案例与宿主固定评分实现交叉检查，正常双类 AUROC/AP、MAE及非恒定 Spearman 无差异。导出自测能拒绝缺行、重复、额外行、非有限数与错误 split，保留本赛模板16379行、BOM、CRLF及非预测字段。上述成功不能替代评分入口的错误输入验收。

模型代码使用冻结编码器，训练头不载入编码器，缩放只拟合该任务 train 内部90%划分；回归还原为原 Y 尺度，不删除重复样本。主 Codex 已在独立、断网、限额容器中验证真实权重 SHA256、2048维输出、冻结状态、重复编码一致及单条/批次一致。GPU 路径尚未实测。

## 主 Codex 接手

原始21份交付文件与四套完整消息已冻结，逐文件摘要见 [原件清单](../comparison-originals/manifest.json)。根目录 `execution/` 是独立运行副本，原件不再修改。
