## Key behaviors vs v3 (the accepted projection)

1. **Leakage-fixed split**: official train grouped by RAW `Drug` string (no canonicalization/dedup/row
   edits/Y edits), groups codepoint-sorted, shuffled by dedicated `random.Random(43)` (algorithm
   recorded; immune to global RNG poisoning; created strictly before model init), whole groups taken
   until ≈10% (target 64). Invariants asserted inside the helper: non-empty/disjoint/exact-coverage/
   no-cross-boundary-drug. Full record (all original row indices, group map, source hashes, dup-ID &
   dup-SMILES audit) → `artifacts/internal-split.json`.
2. **No hardcoded run identity**: hidden_dims/lr/seed/dropout/optimizer/epochs/patience/batch_size all
   read from validated config.
3. **Per-epoch eval/no_grad logging** on fit AND stop with the SAME mode as early stopping:
   standardized MSE + original-scale MAE/MSE, plus batch train loss, lr list, epoch wall time, step
   counts, gradient finite/L1 checks. Assertion ties the logged stop MSE to the early-stop metric.
4. **Best and last heads saved separately** (`caco2_wang-head-best.pt` / `-last.pt`, format
   `hainan_caco2_chemeleon_head_v2`) each carrying full config, split-record hash, epoch/step
   identity; optimizer state + CPU RNG states in `training-state-last.pt` as plain JSON-safe
   containers loadable with `weights_only=True` (probe recorded in evidence).
5. **Exports**: new `artifacts/train-predictions.csv` = best-head predictions for every official train
   row with `split_marker` fit/internal_stop + `used_for_fitting`; existing `artifacts/predictions.csv`
   unchanged schema `task,split,row_index,Drug_ID,Drug,y_pred`, blind valid+test only (91+182=273 rows,
   positional row identity — dataset has legitimately duplicate Drug_IDs incl. `-`).
6. **Feature identity, not cache**: per-split `features-{split}-identity.json` binds content sha of
   features+mask, shape/dtype/NaN counts, input file hash, per-row identity digest, encoder py/checkpoint
   hashes. v4 never reads an external cache this cycle; npz writes are fresh evidence. Array transform
   unchanged from v3 (fill NaN→0, z-scale).
7. All v3 evidence retained: reload-consistency (fresh encoder + weights_only head reload, allclose
   1e-5), encoder before/after full tensor digests, disk hashes re-checked, CUDA device asserts,
   optimizer-excludes-encoder and head-changed proofs, forward-hook event log, parse counts.
