# 分子 ADMET 训练：容易让实验结论失效的地方

用途：首次接入训练包，变更标签、特征、清洗、划分、损失或任务组织时读取。以真实官方文件为准，不从熟悉的公开数据集名称猜标签含义。

## 1. 标签先于模型

为每个任务明确：分类/回归、正类含义、单位、是否已取对数、缺失编码、范围、删失值（如“<某值”）的处理，以及输出需恢复到什么尺度。没有说明的变换不能靠网上同名任务补齐。[项目契约](../competition/contract.json)

- **缺失不是阴性，也不是回归值零。** 采用逐任务掩码；确认 batch 中某任务无有效标签时归约有定义。Chemprop 支持缺失标签，但仍须核对实际适配器。[S1]
- 分类的正类方向必须固定。生物学上的“好/坏”不等于数字 1/0，不能按直觉翻转。
- 对数变换和单位换算可能改变回归问题。训练时若标准化，评价和提交必须按声明恢复尺度；不能把标准化 MAE 写成原单位 MAE。[S2]

## 2. 同一个分子不总是同一行字符串

保留原始样本键与 SMILES，另记用于特征和分组的身份。不同 SMILES 可以表达同一结构；同一 drug_id 也不能默认唯一。本项目提交模板已有重复/空 drug_id，以 [提交契约](submission.md) 的键与原字符串为准。

在约定的立体化学、盐/组分、互变异构体处理策略下检查重复和近似重复。相同结构的不同测量可能反映实验条件差异；不要直接平均冲突标签。把所有重复删掉、把所有分子去盐、去电荷或丢弃立体信息，都需要明确语义和变更记录。RDKit 能执行这些操作不代表本任务应默认执行。[S3]

解析失败必须记录数量、样本和原因，查明处置规则；不能静默删行再宣称完整覆盖。训练清洗不能改写官方提交模板中的非预测字段。

## 3. 划分必须回答我们要检验的泛化问题

官方给定的划分/使用约束优先。若需要自建验证：先确定是预测同分布的新测量、新分子，还是未见骨架；再选择随机、分组、骨架或时间划分。骨架划分不自动“最正确”，也不能替换官方评价。[S4]

若声称验证的是“未见分子”，相同分子及其派生表示/多构象应按组隔离；多任务共享训练时还要明确同分子在其他任务的暴露情况。已知分子的新端点与全新分子的泛化是不同问题，不混称为无泄漏。

特征增强/复制样本应在训练分区内发生，派生样本继承父样本分区。分层照顾类别比例不能突破必须保持的分组约束；稀有正类不足以形成可用验证时，明确报告限制，不能反复重切直到分数好看。

当前 Harness 正式入口支持独立官方 train/validation 原文件；若实际包只有一个标注文件，先实现有父输入、分区索引和哈希的接口，不能把自行切出的文件冒充官方原件。见 [数据政策](data-policy.md)。

## 4. 所有需要“拟合”的处理都要有拟合范围

scaler、特征选择、插补器、训练采样权重、类别权重和任何数据驱动预处理，都记录使用了哪个训练分区。验证/测试通常只应用训练得到的变换；每折独立拟合。禁止先在全量数据上 fit 再切分。[S2][S5]

按固定算法从单个合法分子算特征，与利用全体分子拟合词表/scaler/PCA 不是同一回事。对测试分子的无监督拟合也不能自动视为允许；未确认前沿用团队限制。论文、文档与代码研究可联网，训练资产和运行环境仍按来源政策隔离。

## 5. 每个任务看自己的指标

- AUROC/AP 使用连续正类分数；不要先按 0.5 变成类别再评价。分类概率与 confidence score 语义要清楚，不能为好看随意裁剪。
- 类别不平衡时，准确率不能替代指定指标。另记正负数量，核实训练重采样只发生在训练分区，不改变验证分布。
- 本地 AUPRC 目前实现为 average precision，官方等价性未确认。AP 与梯形 PR 面积不能混用。[S6]
- 在约定的完整验证样本上计算逐任务 AUROC/AP；它们不是可直接平均的 batch 指标。按定义推知，简单平均各 batch 的分数不能代替全体预测的排序评价。[S6]
- MAE 越低越好；Spearman、AUROC、AP 越高越好。不同单位的 MAE 与相关系数直接平均，不能冒充官方总分。
- 排序指标只反映排序的一部分性质；排序好不证明概率校准或回归绝对误差好。不要从单一指标推导未测能力。

确切定义、缺失/无定义处理见 [评价约定](evaluation.md)。库的默认 validation metric 不一定是赛题指标。

## 6. 多任务不是把所有列扔进同一个 loss

显式规定输出头、分类/回归损失、掩码、每任务归约分母与权重。合并数据前检查任务列顺序、样本对应和标签重叠；单个 API 支持多任务不代表混合所有任务类型就自动正确。

记录每个任务的有效标签数和损失贡献。大样本任务、大数值尺度任务可能主导更新；先诊断再选择标准化/权重/分组/单任务实验。任务权重是训练设计，官方评分权重是评价契约，二者不能混为一谈。共享任务变差是需要验证的负迁移假设，不是必然现象。

## 7. 禁外部数据时检查隐藏来源

从随机初始化训练 Chemprop 与加载外部预训练是两种数据来源。官方文档说明 CheMeleon 会使用 PubChem 预训练权重，部分 `v1_rdkit_2d_normalized` 特征含 ChEMBL 拟合归一化参数。[S1]

2026-10-30已记录用户向赛方确认的冻结权重许可；不要因此重新禁用全部预训练。具体资产与附加拟合参数分开核查。本次真实数据的重复标签、验证分布、跨任务暴露与输入失败见 [数据画像](research/2026-10-30/data-profile.md)，选型判断见 [V2](research/2026-10-30/admet-research-guide-v2.md)。

下载资产、读旧缓存、调用外部模型补标签/嵌入/教师分数，先转 data-provenance。禁止因网络被阻止就用宿主机缓存、把权重藏进镜像、抄外部预测数组来替代。发现影响已运行模型时追溯依赖并从允许输入重做，不能只删除下载文件。
