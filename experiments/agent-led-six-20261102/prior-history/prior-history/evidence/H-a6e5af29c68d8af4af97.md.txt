## Decision

Recommend **adaptive breadth allocation with a measurement/identity gate before HPO**. Reject serial deep optimization of one task as the default: the snapshot records five completed learning runs/26 heads (one Mini22 baseline plus four Caco2 runs); replacing baseline Caco2 with its historical best only moves the inferred 22-task valid aggregate 43.6032 → 43.7333 (+0.1301), and even perfect Caco2 with other tasks fixed gives only about 48.81. Reject equal shallow tuning as the final policy: tiny-N, near-ceiling tasks and anomalous regression scales have different information value and costs.

Recommended loop: (1) audit scorer, labels/units, task/split/row identity and cache identity; (2) screen a modest common head across a portfolio; (3) estimate paired normalized-score gain, variance and end-to-end cost; (4) allocate follow-up only to reproducible positive-gain tasks; (5) reserve representation changes until evidence suggests the head is limiting. Falsify this recommendation if matched screens show uniform allocation has higher aggregate gain/GPU-hour without increased variance, or if score-normalization assumptions fail.

Research only: no training, fitting, new scoring, private row-level truth access, installation, remote execution, dispatch or upload was performed or authorized.

## Task interpretation

- Diagnostic screen first: LD50 (n=1937, norm 36.62); solubility (n=2940, 6.23) and PPBR (n=279, 26.03) because raw MAE/reference gaps demand unit/range/identity audit; VDSS (n=113, negative Spearman), half-life (n=67, weak Spearman), CYP2D6 Carbonmangels (n=67, 14 positives).
- Tiny classification tasks: DILI (48; 13 positive), hERG (66), HIA (58; only 10 negatives), bioavailability (64), CYP substrate Carbonmangels (67 each), CYP3A4 Carbonmangels (67). Use small heads and repeated group-aware/stratified splits; explicitly handle one-class splits.
- Larger CYP Veith tasks (n=1210–1313) allow more stable screening, but AP semantics block official comparability.
- High normalized baselines (hERG, HIA, P-gp, CYP3A4 Veith) do not prove a ceiling.
- Regression checks first: units, transforms/inverse transforms, finite/missing policy, task/split/row identity and raw-scale outputs. No label edits, clipping, de-duplication or outlier removal.

## Cache, head choice, ensembles

Reuse frozen CheMeleon embeddings only if encoder weights/buffers, preprocessing, input SMILES bytes, row IDs/order, split, shape/dtype and parse mask match exactly. The same matrix may support multiple heads only with verified identical rows; task-specific subsets require explicit row mapping. Cache reuse saves encoding cost, not statistical dependence. Per-task head choice is acceptable if each is trained only on its own train.Y. Ensembles combine independent predictors and require internal out-of-fold weight selection. Multi-task learning shares trainable parameters and may cause negative transfer; it is a distinct higher-risk experiment, not the first breadth step.

## Selection, uncertainty and stop rules

Use paired seeds and fixed split for H0/H1; report every seed delta, mean, SD, range and failures. Tiny-N tasks need a second split before winner declaration. Fit scalers only on inner-fit rows; valid is aggregate confirmation/diagnostic only, with prior access counted. Predeclare one candidate per task for valid confirmation. Report mean-of-22 aggregate, task deltas, uncertainty and selection bias. Stop a task if gain is not reproducible, is below measured seed/split noise, depends on invalid identity/scorer checks, or its normalized gain/GPU-hour is dominated. Estimate minimum effect from repeated-control noise and practical relevance; no unsupported significance threshold is asserted. Stop portfolio expansion if runner, cache identity, freeze proof or metric fixtures fail. A resource refusal is not a scientific loss.
