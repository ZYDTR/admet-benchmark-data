# 角色任务起草参考

主控根据本次目标写自然语言任务，把材料放到对方确实可读的位置，明确要求使用所交付的当前Skill。以下是交付内容参考，不是固定生成器或按顺序机械执行的SOP。

| 角色 | 主控应交代的结果与范围 |
|---|---|
| 准备 | 使用任务内ml-preparation-only Skill，交付指定科学任务的实现、真实输入/消费接口核验、依赖和未验证项；允许私有依赖及批准资产，不训练、不操作海南。附实际生产/消费接口和独立验收含义。 |
| 准备观察 | 只观察主控已派发的准确request/session，按同一准备结果标准核对原件并回主控。运行中不发提示、不修代码、不追加工作；队列空暂停。 |
| 训练 | 使用admet-frozen-training Skill完成指定科学任务，附输入/底座、科学配置、允许写入、预算、结果验收条件和回报对象。部署、工具和故障处理由执行Agent在范围内决定；真实情况与未验证项留证。 |
| 算力观察 | 使用hainan-resource-observation Skill按既有节奏提供有来源的当前资源记录。只通知登记等待的原训练；不分配训练或准备。 |
| 取回评分发布 | 使用hainan-training-retrieval及admet-evidence-review Skill，完整取回指定run与相关历史，按指定宿主口径评分并交质量材料；发布只限审读后已有授权的具体清单。 |
| Chat网关 | 使用admet-evidence-review及通道参考，将主控研究模板和本批准确事实交给新Pro，收全原件、核对问题覆盖和内容身份后回主控。运输方法按现场选择，不改变研究问题，不派OpenCode。 |
| 主控 | 对科学问题、上下文完整、权限与验收一致负责；亲审实际产物和故障，给出接续决定。若上游含混先修任务，不把一切返工归给执行模型。 |

任务记录实际Skill版本、输入、权限与回报身份支持追溯；格式按需要选择。不要把已经退役的固定准入、封口、渲染或状态检查脚本复制进下一任务，也不为其另造同义流程入口。主控原文和网关小字段分工仍以[Prompt合同](../../design/chat_gateway_20261031/PROMPT_CONTRACT.md)为准。
