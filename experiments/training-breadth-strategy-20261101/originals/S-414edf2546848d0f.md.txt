# ADMET Agent Harness

为兴智杯赛题 159 提供可接续的工程与 Agent 工作环境。Python 3.11+；命令从项目根目录执行。

## 每次进入或上下文丢失

先判断请求是否与项目有关；翻译等无关请求直接处理，不读取项目状态或技能。项目相关任务再读 [当前状态](context/state.json) 和 [唯一技能索引](skills/INDEX.md)，按意图选择一个主技能；仅遇到其条件才加读其他技能，不一次加载全库。续接任务先运行 `python3 scripts/harness.py status`，核对证据和未完成动作，避免重复训练。

## 始终保留的边界

- 遵守当前任务的只读、禁联网、仅规划等明确限制。文档中一般允许研究方法资料，不是覆盖这些限制的授权；离线证据不足就标记待核验。
- 官方禁止其他外部数据；用户已向赛方确认冻结外部预训练权重允许。新数据/资产接入走数据来源技能，普通方法调研不等于接入；冻结许可不覆盖额外标签或任意外部拟合参数。
- [赛事契约](competition/contract.json) 区分官方事实、用户确认、团队默认和未知。已有研究快照与审计，正式数据/标签契约及Docker未接入；完成可做的研究与工程，明确正式运行条件。
- 正式运行只走固定 CLI 执行器；文档不约束宿主机权限。浏览器/MCP/外层 Agent 的权限需按 [宿主集成](docs/host-integration.md) 单独设置。
- 提交中的非预测字段逐行保持原字符串。预测由程序生成；本地校验不等于官方成绩或历史数据使用证明。当前交付不含自动上传。

## 完成与交接

以所选技能验收标准判断完成。任务变更写入 `context/tasks/`，用 `checkpoint` 命令保留版本和证据；重要事实或未知变化同步状态。修改工程后更新 [工作记录](docs/working.md)，分阶段保存版本。只把实际验证的教训写入经验，假设留在任务记录。

## 稳定入口

`python3 scripts/harness.py --help` 查看工具；`check-context` 检查路由结构；`doctor` 查看环境及数据状态。工具输出 JSON；非零退出时保留错误码，按具体阻塞恢复。架构改动才读 [RFC](docs/rfc.md)，接入模型才读 [适配器契约](docs/model-adapter.md)。
