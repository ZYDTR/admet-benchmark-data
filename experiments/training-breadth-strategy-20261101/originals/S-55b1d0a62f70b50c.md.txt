# 兴智杯 ADMET Harness：规则与交付边界独立评审

核验日期：2026-10-29（北京时间）。范围是本次启动设计与四天计划评审；未实施 Harness、训练、修改 Skill、上传或联系赛事方。本文的相对路径以 `adhoc_jobs/admet_harness_startup_review_20261029/original/admet-agent-harness/` 为项目根目录，工作区标准另列全路径。

## 结论

1. **首要缺口是可审计的训练与选模，而不只是 CSV。** 官方当前公开正文要求设计并训练深度学习模型、自动生成预测，且在复现审核条款中将“未根据训练集和验证集调参优化”列入作弊情形。原包 `competition/contract.json` 的 R06 提及复现但未完整列出这一点。应保留真实划分、候选、配置、逐任务验证结果、选模决定与训练/推理链，避免把一次合成接口演示当成参赛训练。
2. **先交一条可训练、可加载、可预测、可复算的真实任务链，再扩展到完整候选。** 现有 demo 不训练，正式数据、适配器和训练尚不存在；四天计划合理作为目标，但 D2 完成 22 任务取决于训练包、标签契约、硬件和实测速度。先通过合成接口协作，再在 D1 下午对真实任务测耗时，按结果重排。
3. **官方明确禁止其他外部数据，但权重、测试分子无监督使用及拟合参数等边界没有逐项解释。** 随机初始化、隔离缓存与 Docker 断网是团队审慎策略，不是官方明文要求。软件代码、依赖与它们捆绑的数据/权重须分别审查。
4. **公开模板实测 22 个任务、16,379 行，`(task, sample_idx)` 唯一；`(task, drug_id)` 有 218 组重复键，按该键去重将丢失 297 行；另有 1 个原生空值。** 保留模板非预测列的原始字符串、顺序与完整覆盖，按身份映射预测。分类正类概率限制 [0,1]，官方也接受置信度分数，后者不宜一概裁剪。
5. **本地评价不是官方评分器。** 原包 AUPRC 是 average precision，是否等价官方未知；满分数值 65.719642 已公开，但混合指标总分公式及未定义情况处理未公开。以同一验证样本、标签和明确指标比较候选，避免把本地加权平均写成官方成绩。

## 最易踩坑及可执行判据

**实际存在的工程缺口。** `docs/model-adapter.md:42` 明确 demo 不训练，适配器及正式数据待接入；`scripts/demo.py` 只能演示格式。拟议合成适配器应覆盖 train → 保存 → 新进程加载 → predict，并用独立接口检查确认权重和预测确由这条合成链生成，明确禁止用于正式候选。真实训练首日再对该链进行端到端验证。

**现有就绪门槛过粗，且数据入口假设可能不匹配。** `src/admet_harness/runtime.py:179` 的 `_task_contract` 要求传入 schema 顶层与其中每个任务都已确认；`runtime.py:270` 对训练强制两种角色 `train`、`validation`，`runtime.py:119` 禁止同一文件路径登记两次，`runtime.py:125` 只接受 `competition_official` 原始输入。如果正式包只有一个标注文件，当前实现不能直接表达其有证据的派生划分。建议按动作及实际选中任务核验，正式数据与派生分区区分父子关系；开发单任务可先推进，但最终候选必须覆盖当前模板 22 任务全部行，且各任务标签语义及预测来源有证据。不要把未验证的 schema 顶层置为 confirmed 来绕过检查。按现接口单次 predict 关联一个训练 checkpoint（`src/admet_harness/candidate.py:106`）；多模型方案还需设计真实产物来源与官方资格，不能假设现状已支持。

**模板映射比药物 ID 更重要。** 本轮解析出 8 个 AUROC、5 个 AUPRC、5 个 MAE、4 个 Spearman 任务，16,379 个 `(task,sample_idx)` 互不重复；`(task,drug_id)` 有 218 组重复键，按该键去重将丢失 297 行，零基行 10846 是 `herg/61` 且 drug_id 空。读取时保留字符串和前导零，按模板顺序比对字段；官方模板是 UTF-8 BOM、CRLF，这两项是当前文件实测，不是额外声称的官方强制编码。`src/admet_harness/submission.py:75` 检查列及键，`:141` 检查有限数与概率范围，`:209` 逐行检查非预测列。脚本通过只证明这部分规则被检查，不证明模型来源或平台已受理。

**验证泄漏和错误选模。** 同一分子的不同记录、不同任务或同骨架若被不恰当地分到训练和验证，会使内部评估偏乐观；实际数据尚未取得，因此这是风险而非已发现问题。保存每个样本的稳定标识与 split membership，明确去重/冲突规则；超参数、早停与 checkpoint 选择仅基于训练及验证，不以盲测标签、外部数据库补标签或反复利用测试结果代替验证。用验证结果选模型本身是正常流程，但复用同一小验证集过多轮会过拟合；控制实验预算并保留一个预先定义的复核分区，如实际样本量支持。

**评价口径错位。** `src/admet_harness/evaluation.py:212` 使用非插值 AP，`:228` 的单类情况按本地约定返回 undefined；`docs/evaluation.md` 清楚承认官方等价性未确认。比较时至少绑定划分成员哈希、缺失掩码、标签变换、代码版本和预测记录；目前记录 `split_id` 本身不能证明样本集合一致。回归反变换、分类正类和 Spearman 方向错误，即使格式正确也会形成无效的模型决策。

**追溯链有限。** `src/admet_harness/candidate.py:100` 交叉检查候选、真实 completed 推理/训练记录及权重哈希，`:129` 对照输出预测；它提高本地一致性，但不能证明历史上未混入外部数据或组织方将认可。`src/admet_harness/runtime.py:290` 随机初始化与 `:314` 断网属于团队执行策略；固定镜像仍要审计是否已有隐藏资产。平台“最后有效版本”可覆盖早前更优版本，故保留候选及提交回执，冻结最终版本后停止临时实验提交。
