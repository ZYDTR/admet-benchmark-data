# 验收策略

## 可在当前环境执行

Python 标准库 unittest：来源/哈希/路径校验，运行计划拒绝条件，提交完整性及排序、空 ID/前导零、score/probability 边界，状态恢复与技能链接检查。真实公开模板用于只读格式分析；测试预测只用于格式验证，不能提交比赛。

命令：`python3 -m unittest discover -s tests -v`；`python3 scripts/harness.py check-context`；`python3 scripts/harness.py doctor`。

## Agent 行为验证

让没有项目编写前情的 Agent 只收到项目入口与自然语言任务。记录实际读取文件链、技能选择、第一项动作、输出/阻塞以及无关内容加载。覆盖续接任务、缺训练数据、外部补标签、缓存权重、提交文件、规则变更、技能修改与无关任务。期望答案仅在评估者记录中，不注入执行 Agent。静态路由检查不能替代此项。

## 需要目标环境的集成验证

Docker 可用且存在经过审查的固定镜像时，运行离线集成测试，验证容器拒绝外连、官方输入只读、缓存独立、产物可回收。当前没有 Docker 时明确记为未运行，正式执行保持拒绝。取得官方训练包及模型适配器后，再做训练和推理完整复现；不可用合成演示宣称模型成绩。

## 完成条件

工程单测及上下文静态检查通过；独立 Agent 任务结果有记录；所有未运行项和比赛接入阻塞可从 `context/state.json` 发现。每项后续修复针对实际失败保留回归检查，避免无目的扩大测试。
