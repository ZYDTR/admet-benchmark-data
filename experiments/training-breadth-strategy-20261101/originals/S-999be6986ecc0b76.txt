# 旧 Harness 的选择性采用

来源：`../admet_agent_harness` 的 AGENTS.md、competition/contract.json、数据/实验 Skill，以及 `../admet_research_intake_20261030/README.md`。路径相对项目父目录；具体摘要见 evidence/source-manifest.json。

| 项目 | 处理及理由 |
|---|---|
| 官方 R01–R10 | 保留外部数据限制、深度模型训练、自动预测、模板、复现、末次有效提交和参赛/许可证要求。 |
| 外部预训练权重 | 原 U02 仅此子项被用户确认更新：允许但必须冻结。外部拟合状态、教师监督、额外样本等不据此自动获准。 |
| 随机初始化 T03 | 不继承为通用限制。新头随机初始化，外部底座加载已批准固定权重。 |
| 本机 Docker、固定镜像、SAP3551 | 属旧执行器，不移植为赛事要求。本次按海南 Skill 宿主直接执行，记录实际环境和可落实限额。 |
| 未部署网关/OS 沙箱 | 仍不能宣称已具备。不作为用户已授权宿主训练的一概阻点；不给普通准备 Agent 通用执行权。 |
| 准备 Agent 不训练 | 旧准备任务继续适用；本次用户明确新建的海南训练执行会话承担真实训练。 |
| valid 标签分离 | 保留为本项目数据控制。官方 valid 原有标签，官方允许用其调参；不可把隔离误写成官方禁令。 |
| no training / check-adapter | 当前授权包含一次真实模型训练，不能机械继承过去不训练任务；离线 scaffold 测试仍不训练。 |
| 数据身份、原Y、原划分、预测模板 | 保留，固定文件摘要与 task/split/row_index；重复或空ID不能用字典覆盖。 |
| 清洗包 | 已审计但未接入本轮；继续用已核验原件。存在文件不等于已批准改变本轮输入。 |
| 外部TDC标签、伪标签、test拟合 | 不纳入本轮；规则未确认和本地排除分别记录，不能宣称已获冻结许可即全部允许。 |
| 原外部评分/量化反馈网关 | 不声称已部署，本轮不评分。未来由主控固定评分器读取预测数据，不执行返回脚本。 |
| 上传/发布 | 本轮无赛事上传、无仓库推送。 |

规则快照的公开条款与用户确认分开保存；执行前或上传前遇到新公告重新核对。保存旧原件，不回写历史规则制造一致性。
