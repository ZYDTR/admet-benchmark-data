# 海南训练产物取回

Workflow。v1.0.0，2026-11-01。主控或用户明确指定的专用取回会话使用。写作依据：[工作区Skill标准](../../../../rules/skills/bestpractice_skill_writing.md)。v0.2 增加本机评分及发布分工；v0.3 增加用户明确选择的公开仓库发布、固定版本链接及逐阶段测速。v0.4 记录本机评分与公开固定版本发布实测及结构化脱敏教训；Chat往返另由网关验收，不能以发布成功替代。

本版共同交接规范见[控制合同](../../control/README.md)与[角色模板](../../control/templates/README.md)。本次任务绑定Skill、命中引用、输入、预算和验收版本；旧run证据不回写。职责之外的规范不扩大本角色权限。

发布候选必须对照主控最新 `control/history-registry.json` 及固定inventory输出，逐项处置全部已有历史，包括最早Mini 22任务基线、准备对比/未就绪底座、失败和评价使用史。只搬本批run然后写partial不满足正常全历史交接；可用未收项先补齐。原来没记录/需新实验的缺口如实保留。源文件在本机可定位不代表公开可读；来源和衍生件逐项绑定固定URI，发送前由CONTEXT_CONTRACT检查。

## 目标与唯一连接入口

把指定训练的质量分析材料完整、可追溯地取回本机，证明取到了什么、缺什么、是否逐字节一致，以及各阶段花了多久。优先保留原始材料，摘要作为衍生产物单独生成。2026-10-31 用户明确本角色还负责本机 valid 评分及证据打包/发布，任务级/分组级精确汇总评分和技术诊断可由主控纳入准备/训练反馈，逐行valid真值与残差仍只在获准的评分/分析范围内。规则见[评分与发布](references/scoring-and-publishing.md)；取回角色与 Chat 双向网关保持分离。

所有海南连接必须先完整读取 [hainan-compute-access](../../../../rules/skills/hainan-compute-access/SKILL.md) 及其 [连接基线](../../../../rules/skills/hainan-compute-access/references/connection.md)。原有Windows通道、双层严格主机密钥、private-compute/UID1012、Michael目录边界、凭据仅内存和有界恢复全部继承，不另维护更宽的连接规则。只读连接脚本的三个动作不能替代本任务明确授权的文件取回；扩展实现仍须审读实际命令及副作用。

ADMET取回另读 [宿主唯一入口](../../AGENTS.md) 和对应policy。它的训练计划不赋予本取回任务训练权。本次范围由独立的 `RETRIEVAL_TASK.json` 指定，包括源run、可读依赖、主控本地参考、落地目录、预算及是否实测全量传输。

## 质量材料的覆盖

对已获准的独占run，默认递归清点全部内容，取回所有与该作业相关的普通文件。不能只复用旧collector的固定子目录白名单而漏掉assets或特征cache。未识别的run内文件先保留并登记用途未知；明确无关或重复才可排除，逐项解释。

| 类别 | 应保留的已有原件 |
|---|---|
| 实验身份 | run/计划、实际配置、完整执行源码与补丁、固定资产版本、启动命令及环境摘要、历史尝试和决策依据。 |
| 输入与划分 | 实际train及获准盲输入、原始行身份、内部划分索引、变换参数、单位/标签转换、解析和截断/失败掩码。 |
| 学习过程 | 已有epoch/batch指标、学习率、梯度统计、优化步、最佳轮次/早停、恢复和失败日志。 |
| 预测与表示 | 已生成的逐样本预测、底座表示/特征缓存、预处理结果、顺序和缓存身份；保留空/重复ID和全部原行。 |
| 模型状态 | 原底座资产、最佳/最终头、已有中间checkpoint、优化器和随机状态、冻结前后参数/buffer证据。 |
| 可复现环境 | 解释器及依赖清单、版本/摘要、项目定制代码/二进制、精度和硬件/驱动记录。当前环境快照须标注采样时间，不冒充训练当时状态。 |
| 运行与异常 | 作业相关stdout/stderr、退出状态、OOM/资源样本、系统调用轨迹和拒绝记录，包括失败尝试，保留其与本run的关联。 |

权重或输入跨run完全相同，可在日常取回中使用已经逐字节核验的本地对象并写明引用。**测速任务要求全量重新传输时，不能拿历史本地副本冒充本轮下载**；分别报告新下载和复用字节。依赖安装目录可按任务仅取元数据而不复制全树，但须列为明确排除项及复现限制，不能宣称全环境快照。

没有保存的train预测、batch日志、中间checkpoint或优化器/RNG状态应记 `not_recorded`，不能通过重新训练/推理补造原轮证据。相关文件不可读与当时没生成是不同状态。保留完整性与语义质量两个结论：文件全取回不证明训练科学结论正确。

## 执行边界

- 远端只读：清点、读取、哈希和从stdout流式传输；不在海南或Windows创建压缩包/临时文件、安装依赖、改权限、停止服务或清理文件。普通Python读取使用隔离模式及禁pyc；不导入会初始化CUDA/写缓存的训练框架。必要系统元数据仅限身份和与本任务相关的环境，不扫描他人目录。
- 本机只写当次明确登记的取回目录、私有评分输出与发布工作副本；这些不同用途的路径须在任务清单中列清，不能把“只写取回目录”误用于阻断已授权评分/发布。保留原件、失败尝试和日志。历史run、Skill、验收标准由主控维护，执行方不得修改。不执行原始模型/pickle、不加载模型、不训练或推理；张量/归档结构检查使用不执行代码的读取方式。已获准的固定预测评分仅按评分与发布参考执行。
- 凭据不进入argv、产物、报告或工具输出。结构化文本错误可脱敏；二进制产物流不能做字符串替换或编码转换，防止字节损坏。密钥/身份变化和真实文件权限拒绝为硬失败；短暂连接异常遵守连接Skill的有界退避，取回失败留下partial，不能伪装成功。
- 身份及终态核实后才固定快照。验证路径、真实祖先和挂载，远端清点不跟随符号链接，不自动越出批准根读取依赖。特殊文件、链接或路径漂移单列拒绝/缺口，不能悄悄跳过后报完整。读取多硬链接普通文件须登记且限真实批准路径，只读不修改；本地不要重建硬链接。
- 本地解包拒绝绝对路径、`..`、符号/硬链接、特殊文件、重复归档名称和越界目标；设声明大小/总量预算，独占目录中排他创建文件，不使用可能覆盖原件的解包或同步删除选项。
- 只有任务相关授权材料能取回；远端不搜集验证/测试真值。用户已指定的本机 valid 评分仅访问登记的真值来源和固定评分器。发布阶段按评分与发布参考处理，保留接收对象、材料范围和读回证据；上传到共享文件区与向 Chat 发送分析消息由不同角色负责。本Skill不自动新增训练、会话或定时。

## 完整性和测速的证据

清单应至少保存每个对象的相对路径、类型、字节数、SHA256及来源；目录和拒绝项也纳入覆盖统计。远端清点前后核对文件集合和内容摘要，结合终态记录判断源是否稳定。变化的文件进入 `source_changed`，重试另存独立attempt；不把两次不同源状态拼成同一快照。

接收后逐文件验证路径集合、字节数和SHA256，记录缺失、额外、摘要不符。再次从远端只读核对快照身份；不能仅把归档内部清单当作完整源目录证明。历史本地清单可作第三方对照，但本轮仍须直接读取远端。对输入CSV、预测行数/身份、配置、训练记录等做不训练的结构检查，保留全部异常。

计时使用本机单调时钟，记录UTC原始时间及北京时间展示：

- `setup_seconds`：读规范、准备实现及离线检查，单独记录，不混入网络速度。
- `connect_seconds`、`inventory_hash_seconds`、`transfer_seconds`、`local_verify_seconds`、`remote_recheck_seconds`：各阶段实测；无法拆开的阶段明确标组合计时。
- `retrieval_wall_seconds`：首次连接开始到所有取回校验结束的真实墙钟时间，包括退避/重试；`total_task_seconds`另含准备和交接。
- 文件数、未压缩原始字节、实际收到归档字节、重试次数和复用字节。归档字节/传输时间只能称接收有效吞吐，不能称包含SSH开销的链路带宽。无独立传输阶段计时就不编造纯网络吞吐。

成功条件是：批准范围内所有项目均有处置记录；应取文件集合、大小和SHA256完全一致，源稳定；必要结构检查有结果；计时口径和缺失/未验证项明确；无远端项目写入。无法证明远端无写入时如实写审阅依据及限制，不宣称全服务器零副作用。源缺记录可给“现存文件完整、质量材料有缺口”，不能把两者混成全通过。

## 交付

独占取回目录至少有 `RETRIEVAL_TASK.json`、`source/`（取回实现）、`raw/`（命令/错误/原始流）、`snapshot/`（解包原件）、`manifests/`（前/后/本地摘要）、`timing.json`、`coverage.json`、`verification.json`、`REPORT.md`、`status.json`。原件只读消费，分析或格式转换放另一个目录。报告列出完整性结论、文件数/字节、各阶段耗时、质量材料缺口与排除项、是否读过私有标签/执行计算或远端写入。

专用取回Thread是叶子执行者，亲自完成，不再派Agent、Thread或CLI模型。主控独立检查原始清单、哈希、时间证据和范围，不能用执行方success字段直接认定通过。

## 已验证范围与取回教训

2026-10-31 首次全新 Sol/xhigh 会话完成真实只读取回，主控独立复算通过：[验收记录](../../retrievals/hainan-follow-full-20261031/acceptance/report.md)。302 文件、110.81 MB 原始数据，归档 44.11 MB；传输 66.97 秒，连接至字节校验结束 77.42 秒，全结构/范围检查结束 338.94 秒，整个执行会话 575.06 秒。批准范围内文件全覆盖，未记录的训练信息仍有缺口。实测仅覆盖该完成且稳定的 run、当前连接与约 111 MB 规模，不能据此保证所有规模、异常分支或全依赖环境可复现。实测时使用的 Skill 原文和摘要保存在该取回任务的 control，以下教训在终态验收后补入。

- 原 CSV 可能带 UTF-8 BOM；结构读取沿用原数据解析约定，不能把 BOM 误认成字段缺失，更不能为通过检查修改原件。
- 交付清单须在所有被收录文件的写入进程结束后固定；第一次自验曾因 finalize 的 stdout 仍在写入导致清单过早固定。修正衍生清单时保留旧版及原因，原始归档不变。
- 全任务计时应覆盖首次规范阅读；若计时标记稍后建立，标明下界，并用可信 Thread 起止记录补充完整会话时长。下载结束、全部检查结束和交付结束分别报告。

2026-10-31 公开链接首测的取回、评分和发布分支已验证：[本轮入口](../../exchange/trials/public-repo-20261031/AGENTS.md)，[主控发布复核](../../exchange/trials/public-repo-20261031/acceptance/independent-publication.json)。全新取回302文件/110.81MB，字节校验72.29秒；两run的Caco2各91行MAE由主控独立Decimal50复算一致。公开393文件/32.93MB，push4.54秒，匿名逐文件读回23.55秒；一次SSL EOF经有界重试成功。首次包装、修复和审读耗时另计，不能把传输速度当端到端时长。Chat实读与六产物往返以本轮主控报告为准。

- 结构化脱敏曾误把化学结构中的方括号和圆括号识别为Markdown链接，损坏JSON数组。JSON/JSONL须按原结构解析，只改确实属于基础设施的字符串；验收逐层保留键、类型、数组长度、数值、布尔值、空值和科学字符串。Markdown转换仅用于正文且避开代码块，Python/日志/CSV不套Markdown正则。仅能再次解析不够，必须和源语义对照。失败衍生件和原件保留。
- 科学字符串包括SMILES、scaffold、样本身份和标签/预测；脱敏不得改变它们。审批清单同时绑定来源、衍生件和差异，封口后变更重新验收。
- 单任务评分包装首次曾因LF/CRLF的盲投影约定不同而在指标调用前被拒绝。应读原投影的序列化约定，修包装而不改原件；保留首次失败及实际真值访问、指标调用次数，不能声称失败之前没有接触真值。
