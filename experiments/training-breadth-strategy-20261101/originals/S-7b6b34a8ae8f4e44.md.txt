## 4. 关键设计决定

- **纯标准库**：容器外任何 Python 3.9+ 可跑，不依赖 numpy/sklearn/scipy（本机亦无）。
- **指标语义**：AUROC 并列计 0.5；AUPRC 用 sklearn 式步进 AP（明确为本地口径）；
  两者与官方实现的一致性未确认。分类标签强制 {0,1}，违规记 error 而非静默处理。
- **评分**：只评分显式传入的标签；目录式标签须与项目内无标签副本逐行一致才评分
  （防错位）。undefined（如单类 AUROC）与 error（合同违规）分开：前者退出码 0。
- **导出**：逐行原字符串拼接（保留 BOM/CRLF/引号/空 ID/行序/16379 行），逐行重解析
  自检 + 整体回验 + 原子写入；缺一行/重复一键/非有限值/映射未核实即拒绝，绝不补值。
- **不产出官方总分**：宏平均仅在报告中标 `local_unofficial` 前缀。

## 6. 主 Codex 的下一条命令（从项目根目录，Python 3.9+）

```bash
# 0) 可选：复跑本轮证据（只读，各约数秒）
python3 output/data-eval/run_admet_eval.py selftest  --report output/data-eval/reports/selftest_report.json
python3 output/data-eval/run_admet_eval.py verify-inputs --report output/data-eval/reports/inputs_report.json

# 1) A 路推理产物就绪后（预测 CSV：task,split,row_index,y_pred，valid+test 全覆盖）
python3 output/data-eval/run_admet_eval.py check-predictions --pred <pred.csv> \
    --report output/data-eval/reports/check_predictions_report.json

# 2) 真实验证评分（标签目录：每任务官方格式 <task>.csv；或长表 CSV task,row_index,y_true）
python3 output/data-eval/run_admet_eval.py score --pred <pred.csv> --split valid \
    --labels <labels_dir_or_csv> \
    --report output/data-eval/reports/score_valid_report.json \
    --report-csv output/data-eval/reports/score_valid_table.csv

# 3) 导出官方格式提交（模板默认 data/official/submission_template.csv）
python3 output/data-eval/run_admet_eval.py export --pred <pred.csv> \
    --output <团队名-小分子药物预测技术创新赛-YYYYMMDD>.csv \
    --report output/data-eval/reports/export_report.json

# 4) 回验提交文件
python3 output/data-eval/run_admet_eval.py validate-submission \
    --submission <团队名-小分子药物预测技术创新赛-YYYYMMDD>.csv \
    --report output/data-eval/reports/validate_submission_report.json
```

说明：`score --labels data/official/data_benchmark --split train` 可对 train 做管线自检
（train 标签就在原件内）；test 若将来取得官方标签，同样用 `--split test --labels ...`。
