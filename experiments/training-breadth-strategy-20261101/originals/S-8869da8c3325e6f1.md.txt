# 实验记录模板

复制 A–D 节到 `context/experiments/<experiment-id>.md`，在 [共享总览](../context/experiments/INDEX.md) 认领。一个记录可以对应一组明确相关的 trial；每个真实执行仍有自己的 run_id。本文件中的占位符不是已经发生的实验；记录内的代码路径均相对项目根目录。

记录是工作约定，不是新增 CLI schema。正式数据、适配器和执行仍按既有接口检查；只写计划/只读比较不创建训练 run。缺项写 unknown/未运行及下一步，不填造数字。

## A. 开始前：先填够做决定的信息

| 字段 | 填写内容 |
| --- | --- |
| experiment_id / owner / 日期 | 唯一 ID、负责完整闭环的成员 |
| 状态 | planned / running / evaluated / inconclusive / promising / confirmed / deferred / failed；不是 runtime 的状态枚举 |
| 当前问题 | 一句话，可被结果改变的判断 |
| 触发证据 | 实际 run/记录/错误路径；纯提案写“尚无结果” |
| 假设及替代解释 | 主要假设；最相关的其他原因 |
| baseline | 实际 run_id、对应配置/代码/模型证据；尚不存在则先建立基线 |
| 比较类型 | 单一变动 / 联合搜索 / 整体方案 / 工程诊断 |
| 研究变量 | 要比较什么，以及理由 |
| 配套调参 | 哪些参数分别优化；范围、采样方式和理由 |
| 固定条件 | 哪些保持一致；为什么这个限制可接受 |
| 可比性 | 数据与实际分区身份、样本/标签/缺失签名、评价实现版本；不能只有 split 名 |
| 目标与选模 | 逐任务指标/方向、checkpoint 规则、早停/评价频率；本地汇总如有需明确公式与非官方性质 |
| 预算 | 最大 trial 数、单次时长/资源、总预算、截止点、并发与确认预算 |
| 预期判据 | 哪些结果支持/削弱假设；继续/停止/确认条件；不要事后更换标准 |

数据/标签细节引用现有不可变版本，不必复制到每条记录。源文件 SHA、划分算法/索引、scaler 拟合范围、随机种子、实际依赖/硬件和初始化来源必须能从引用找到。缺引用会限制比较结论。

## B. 执行时：保留全部计划内 trial 的去向

| trial / run_id | 具体改动 / 配置引用 | seed / 分区 | 状态 / 失败原因 | 指标文件 / 预测 / checkpoint | 实际时间 / 资源 |
| --- | --- | --- | --- | --- | --- |
| 待运行 | 待填写 | 待填写 | planned | 未产生 | 未测量 |

表内只存路径与简要结论，不粘贴完整日志。列明中止/跳过/失败的 trial 和理由，不能仅挑最好的一次。实际搜索空间、预算或判据变化时追加日期和原因；不重写历史。

需要的曲线/诊断：train-eval 与 validation 的逐任务表现、loss、学习率与选中 step；资源和梯度诊断按问题补充。注明数据单位、eval 模式、缺失/有效样本计数。不是所有实验都需要额外跑统计检验。

## C. 结束后：把事实与解释分开

1. **观察**：实际输出和逐任务结果；标记 undefined、失败与未完成。
2. **可比性**：comparable / incomparable / insufficient_evidence，及依据；详见 `docs/run-comparison.md`。
3. **相对基线**：每任务差异及方向；必要的重复结果；成本与推理代价。
4. **解释**：假设被支持、被削弱，还是证据不足；还没排除什么。
5. **结论范围**：哪些数据、划分、表示、配置、预算下成立；不能直接外推到整个模型家族。
6. **决策**：继续探索 / 追加确认 / 暂停 / 保留候选 / 修复工程；下一动作、负责人、资源。
7. **重新打开条件**：数据/标签版本改变、训练问题修复、更充分预算或新的可区分假设。

可记录的负结果示例：“当前配置在该分区和预算下没有稳定超过基线”。不能写“GNN 永远不行”。OOM/bug 记录为工程失败；少量种子无稳定差异记录为证据不足，不强行判赢家。

## D. 同步团队与交接

更新共享总览的一行和短结论，指向本记录与实际产物。将稳定有用的代码合并进共享实现；失败或未采纳的实验也保留可定位的代码版本/配置。不要把实验结果堆进 AGENTS.md 或 Skill 主体。

完成后通过现有 `checkpoint` 命令保存任务交接，引用本记录与真实证据。若有数据/评价错误，列出受影响的旧实验，不仅修复最新一条。

设计依据：[训练决策](training-principles.md)、[搜索与选模](search-and-selection.md)。模板字段为团队建议，不是赛事要求提交的全部材料。
