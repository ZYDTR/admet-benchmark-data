# V1 → V2 修订与独立验证

日期：2026-10-30。V1先于深度模型研究保存并交付，完整保留；V2依据实际数据、原始来源与反方审阅修订。本页区分实际发现、真实误读修正和未来风险，避免把一般防范措施写成既往事故。

## 1. 变化不是“把V1写得更长”

V1已经有版本、冻结、许可、对照、证据状态、反方和停止原则。实做显示，仅列这些词仍可能让接手Agent把正确原则用于错误对象。V2把判断对象、证据范围、局部阻塞和下一步动作写得更明确；模型事实放在候选卡，实际数据放在画像，不塞进长期规则。

| 实际发现或观察 | V1还可能留下的误判 | V2具体改动 | 依据 |
| --- | --- | --- | --- |
| 官方概述和67CSV不一致，TDC同名任务规模也不同 | 依据名称补单位、split或不存在的特征 | 字节观察/背景/映射状态分列 | D01–D03、R01、E01 |
| MiniMol有head搜索和集成；runner自动取TDC/test.Y | “模型能用”被扩大为“官方demo全部能跑” | 资产接口与评测流程分开；完整方案身份 | M01–M02 |
| CheMeleon probe先微调再冻结 | 只检查最终frozen标记 | 检查完整参数更新时间线 | M03–M05 |
| 新附件有冻结消融，旧主表没有 | “本次没找到”写成不存在 | 对关键限制查SI/后续版本；不强制泛读所有附件 | M03–M05 |
| CheMeleon网页许可抽取空白，官方API有MIT | 无法抓取被当成无授权，或借用代码许可 | 资产级来源、失败状态、定向替代原始入口 | M04 |
| MoLFormer full-XL/10pct不同，TabPFN有v2/2.6/3.5 | 论文、默认包、权重拼成虚假同一候选 | 每项成绩绑定确切资产、版本和协议 | M07、M11–M12 |
| Uni-Mol冻结后前处理仍随机；本批有388原子和解析失败 | 冻结自动等于固定特征与全行可用 | 输入覆盖、状态、随机性、缓存身份分别检查 | D03、M08 |
| 重复SMILES带不同Y、空ID、模板ID字符串差异 | 分子去重变监督聚合、ID被数值化 | 行/分子/测量/标签四层身份；只写y_pred | D02–D03、R01 |
| 跨任务原串重合4,798；独立heads没有共享可训练参数 | 全部判泄漏，或把表示复用当MTL收益 | 标签级来源、明确共享参数与对照 | D02、评价专项 |
| 审阅发现Ames单骨架、LD50/solubility空骨架valid | 零交集被当成代表性充分 | 隔离与覆盖并列；补充train内诊断，保留官方valid | D03–D04 |
| 未暴露子群仅3条0正类等 | 强制分层出分，即声称解释迁移 | 先核可估计性；约定返回数不冒充科学证据 | D05 |
| 反对预训练的论文也清洗/重切或预算有限 | 只审推荐方，不审反方 | 对所有方向统一审协议、来源关系和激励 | B01–B05 |
| 各专项各自推荐多个pilot | 合并成不可执行的大名单 | 全队总名额与不同问题价值，不按家族均分 | 独立接手审阅 |
| 单位、聚合、个别资产仍未知 | 一个未知阻塞全部研究 | 明确“可继续/受阻动作”的映射表 | 数据与决策审阅 |

AP实现可能反转排名属于人工例子支持的**未来风险**，不是本赛实测事故；已写为触发式有限检查。所有模型收益、GPU成本与完整覆盖仍未实测。

## 2. 冷启动任务设计

使用三个没有继承聊天历史的新Agent，均只给真实任务和项目`AGENTS.md`入口，自行选择资料；明确只读、离线、不训练，不许阅读本验证报告或其他validation输出。任务提示没有给预期答案、推荐文件链或修复结论。测试只输出答案和实际读取路径。

| 场景 | 原始业务问题 |
| --- | --- |
| 候选选择 | 队友因CheMeleon论文成绩好，建议22任务统一采用且集中全部预算；要求提出决定与下一轮安排 |
| 数据与MTL | 队友准备合22表、重复平均、统一标准化和共享网络，用现有valid选优；要求审查与可讨论研究设计 |
| 窄资产查询 | CheMeleon权重页只抽取到License标题；要求离线核实现有许可证据与完成程度 |

## 3. 实际结果

| 真实试用 | 实际读取与表现 | 判断 |
| --- | --- | --- |
| [候选选择](validation/cold-choice.md) | AGENTS→state/INDEX→experiment→研究入口→V2→候选/数据/来源；读12份文件。保留CheMeleon为pilot，提出两条冻结路线和必要对照，区分微调主表/冻结消融，给出升级和停止条件 | 达到本场景预期；未训练、未联网、未读测试答案 |
| [数据与MTL](validation/cold-data.md) | AGENTS→experiment→V2/数据/既有评价指导→聚合JSON；20次文件读取。保留测量行和逐标签角色，设计独立MLP对共享MLP，识别单骨架与单类子群限制 | 达到本场景预期；使用原则形成新的MTL设计，不只是复述候选名单 |
| [首次窄资产查询](validation/cold-asset.md) | data-provenance→候选卡CheMeleon项→来源与当前状态；答案正确，但为取得原始元数据搜索了项目外临时研究目录 | 内容通过；暴露可移交性缺口，不能称原交付自包含 |
| [仅项目目录复测](validation/cold-asset-portable.md) | 新Agent仅准读项目内，data-provenance→候选卡→内置Zenodo响应→契约/相关待办；13个不同文件、14次读取，未加载整份模型综述 | 修复后通过；区分规则许可、权重MIT元数据和尚未完成接入 |

**实际修复：**将CheMeleon发布方API元数据以及已核的其他模型资产元数据纳入项目evidence，候选卡加直接链接；再用新Agent在仅项目目录限制下复测。未向复测者透露缺口或预期答案，也未让它读取首次结果。

完整任务范围见 [任务清单](validation/cold-task-manifest.json)；文件记录的是原始业务问题的摘要，未冒充逐字工具日志。原始输出保留实际路径与并行批次，不虚构工具完成顺序。两份研究审阅也保留：[证据反方](validation/evidence-skeptic.md)、[接手者原始审阅文本](validation/decision-reader.txt)。后者保留当时工作目录中的历史相对路径，不作为当前导航入口；当前采用的证据位置见来源索引。功能试用者被明确禁止读取这些材料。

本轮共4次功能任务，覆盖3类问题，其中1次针对真实交付缺口复测。验证支持这些场景下的路由、证据解释和离线接续；不证明任意模型或任何长上下文都不会犯错。

## 4. 工程验证范围

本轮不改训练执行器或评价算法，不把以前的71项工程测试当本轮新增模型测试。

- V1与先行版本逐字节一致，SHA256为`b48eeb645cec68e7096344149cf838e0dee1524881d343cce022646f92ace71a`。
- 将标准库审计改为显式输入/输出参数后实际运行；22任务明细、总计均与原审计一致；当前官方模板比较再次得到7,611个ID字符串差异。
- 化学、骨架复算、MTL暴露三个脚本与实际执行的版本逐字节一致。骨架复算的66个源哈希和计数与原审计一致；主线程另复算关键结构分布与两个小子群。
- 项目仍为8项局部技能，AGENTS23行、INDEX16行；静态链接检查通过。最终计数与结果见 [结构检查](validation/context-graph.json)。
- 当前规则、数据来源和任务状态已同步，旧“没有数据/所有外部权重未获准”的现行描述已修订；历史V1及旧验收记录保留日期。
- 未运行候选模型、Docker或正式比赛训练；正式输入/适配器/冻结接口仍待接入。

机器可读核验见 [核验摘要](validation/verification-summary.json)。本轮到此停止额外测试，不用无关工程套件代替这些具体验收。
