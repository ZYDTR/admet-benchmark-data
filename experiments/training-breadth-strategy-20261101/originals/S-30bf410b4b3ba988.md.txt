# 可追溯实验

## 目标

把一个明确实验问题变成可比较的逐任务结果、对应模型和可恢复运行记录。

## 验收标准

- 声明本次问题、假设与替代解释、真实基线、数据/划分/评价约定、研究与配套变量、选模依据及预算；比较条件支持所声称的结论。
- 启动正式运行时，`check-data` 与 `plan` 通过；固定适配器和本地镜像经过审查，训练输入不含测试文件。只读比较不要求启动训练或具备 Docker。
- 运行完成有可核验 artifact；崩溃或超时保留失败记录，不能写成 completed。已有成功 run 不重跑覆盖。
- 逐任务指标与本地汇总明确命名；未知官方聚合公式时不输出官方总分。缺标签或指标不可定义时显式报告。
- 深度模型实际训练证据由模型适配器提供；Harness 的格式检查不能证明模型质量。
- 选择下一步时先核对证据，不能把曲线模式当唯一诊断；记录停止条件与结论范围，不靠最佳单次分数宣称架构胜出。

## 资源与边界

按当前意图读取以下资源，不一次全部加载。恢复先看 `status` 中证据与 next_action；新输入、外部权重、补标签或未知来源先转 data-provenance。

| 当前需要 | 读取资源 |
| --- | --- |
| 论文/模型调研、冻结路线、候选优先级或研究接续 | [调研入口](../../docs/research/2026-10-30/README.md)；研究判断读V2，窄查询只读对应证据 |
| 不知道下一步、设计方向或复盘盲目调参 | [训练决策](../../docs/training-principles.md)；查 [实验总览](../../context/experiments/INDEX.md) 避免无意义重复 |
| 损失/指标异常、学不动、不稳定、OOM | [训练排障](../../docs/training-diagnosis.md)；只加载相关实际证据 |
| 改标签、清洗、特征、划分或多任务损失 | [ADMET 风险](../../docs/admet-training-pitfalls.md)；接口变动才补读模型接口 |
| 扫参数、比较架构、确认微小收益或选候选 | [搜索与选模](../../docs/search-and-selection.md)；比较实际结果再读比较契约 |
| 认领、记录或交接一组实验 | [记录模板](../../docs/experiment-template.md) 与实验总览 |
| 只比较已有结果 | [比较契约](../../docs/run-comparison.md) 和指定证据；不因 Docker/训练数据未接入阻塞只读比较 |
| 启动正式运行 | [运行契约](../../docs/runtime-contract.md)、[run.example](../../config/run.example.json) |
| 接入/修改模型；设计评价 | [模型接口](../../docs/model-adapter.md)；[评价约定](../../docs/evaluation.md) |

`plan --config <项目相对路径>` 仅生成检查后的计划；`run --config ...` 才启动正式执行器。Docker 不可用就报告运行阻塞，不改成宿主机执行。无训练数据可运行 `python3 scripts/demo.py` 验证工程，并将结果明确标记为合成演示。

指导文件是团队工作约定；不是官方新增交付要求，不提供自动搜索调度或未实现的预算强制保证。纯设计/诊断可以在无训练环境时完成，不能为了补齐记录伪造实验。

涉及本次真实数据的清洗、划分、MTL或模型适用性时，补读调研入口中的数据画像。用户已确认允许冻结外部预训练权重；当前执行器尚未实现相应资产接口，这限制正式运行，不阻止只读研究或实验设计。单位未知不阻止对给定数值Y的基线设计，但不授权额外语义变换。

## 输出

实验计划与解释写入 `context/experiments/<experiment-id>.md` 并更新总览；实际运行产出新 `runs/<run_id>/`，由执行器保存计划、快照、日志、结果与哈希。只读比较产出 `deliverables/comparisons/<comparison-id>.json` 与交接，指向真实证据；没有结果时报告证据不足，不创建训练 run。恢复训练使用新 run_id 和有记录的恢复设计；失败运行不能直接假装续训成功。简单的只读解释无需为了满足模板而新建实验。
