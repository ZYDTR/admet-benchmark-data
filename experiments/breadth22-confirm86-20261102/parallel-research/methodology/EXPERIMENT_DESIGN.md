# ADMET 实验研究纲领

2026-11-02。主控制定问题、研究者形成方案、准备方实现科学接口、训练方执行已登记实验时共同使用。本文是本项目长期指导，不是某轮临时补件；具体任务和数据权限由项目入口与当次任务确定。依据工作区 Best Practice Skill Writing，以可证伪结论和可比较实验为目标，不规定固定CLI或全流程脚本。

## 每次实验应带来什么

先说明要解决的质量问题、已有证据、竞争解释，以及哪种结果会改变下一步。候选可以广泛，实际矩阵按信息收益、实现准备度和完整周转成本排序；一次研究支持多个批次和条件分支，避免每训一个头再等待一次研究。已完成的等价对照直接复用，重新运行须有明确新增信息。

比较单位包括任务、输入版本、冻结表示、fit/stop划分、预处理拟合范围、训练目标、早停、seed与外部指标。单因素实验确实只改变一个因素；多因素组合先归因于整体，必要时再拆解。模型seed变化与划分变化分别登记。两seed是有限稳定性证据，反复使用Valid会产生选择偏差，不能把一次最佳值或新会话当独立泛化证明。

## 可复用的方法与适用条件

| 方法 | ADMET中的判断和交付 |
|---|---|
| 冻结表示与简单对照 | 在相同特征上考虑线性/逻辑回归、正则回归与现有MLP对照，先判断复杂头是否带来稳定收益。简单头需要新接口时明确标注；纯经典模型能否作为正式参赛模型另核规则，研究对照与提交资格分开。 |
| 表示和缓存 | 把表示、池化、特征尺度与获准冻结底座作为科学因素。缓存绑定原行、编码器和配置；每个fit划分独立拟合统计。共享编码降低重复成本，不假定大底座更好。 |
| 与任务匹配的目标 | 结合类别不平衡、标签分布及评价指标，比较适用的损失/权重/尺度。权重仅从train-fit统计；加权与不加权保留对照。训练loss、早停指标、外部指标及预测尺度分别具体定义。 |
| 更可靠的泛化检查 | 在官方train内部评估规范化分子身份、相似性或scaffold分组的压力测试价值；原始行和官方分区保持不变。先查已有划分，不能凭分组方法缺失认定官方泄漏，已看过的Valid也不能事后重新宣称独立。 |
| 分歧和困难样本 | 优先复用现有预测，以跨模型/seed分歧、极端预测、与train相似度及分子切片发现机制线索。分歧只证明意见不同，不能证明谁错。无逐行真值准入时不计算残差、不推断答案；小分组不得变成个体答案侧漏。 |
| 分阶段分配预算 | 便宜且能区分假设的筛选、共同seed确认、少量新表示探索可以组合。给继续/停止/跳过条件和对照复用账；新工作成本未知才做有信息量的测量，不为每个已知小头再建试跑流程。 |

跨任务保持覆盖，又允许分类、排序和回归任务采用不同策略。对改善、退化、方向不一致分别解释；一项预处理有效不能推广到所有任务。下一批指南写到执行方无需猜测科学参数，同时允许其自行解决工具、部署和运行细节。

## 沉淀与验收

研究结果必须落入持久实验索引、问题账和结论事件。每个方向对应历史已做/未做/已否定/有条件复试的证据；旧结论被推翻时保留旧事件、反证和影响的方案。一次完整交付含具体矩阵、可执行准备指南、成本及未知项。研究者可用代码做获准的数值诊断，但不能将推理或计算结果冒充真实训练或官方评分。

主控评估新增主张和下一动作，复用已有可靠评分、冻结与运输证据，不重做整份研究。用户要求结果优先于过程，验收依据是科学问题得到可检验回答，而非工具调用数、报告长度、脚本PASS或多个模型口头赞同。

## 外部来源与迁移边界

启发来自用户指定的[车库DINOv3 Skill固定版本](https://github.com/grapeot/dinov3-classifier-skill/blob/45f5bb6336470ebd534b2e81f1684366b63fd8b2/skills/skill.md)。它提供冻结表示、轻量预测器、分组验证、表示选择和模型分歧审查的范例；以上ADMET应用是本项目的选择性改写，其案例收益不证明药物预测收益。

不移植其图片人工改标签、视觉伪标签、外部参考集流程、F1阈值优化、部署蒸馏或固定CLI操作。ADMET当前使用原始实测标签，只学习train.Y；外部预训练参数及buffer冻结，禁止test拟合，valid用于指定评分/获准分析。AUROC/AP用连续分数，不能用硬阈值替代。数据和规则来源以项目policy为准。
